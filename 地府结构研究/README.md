**本目录原 README 的内容不再重述，因为其中三处已被核实为错误**，正确说法见
`docs/lore-verification/verify-cn-structure.md`：

- 「法律依据：《冥律》（又称《阴律》《玉历宝钞》）」——**不存在**成文冥律。「冥律／
  阴律」是笔记小说中的观念范畴，《玉历宝钞》是一部具体的清代善书（逐殿叙述体，
  无条款编号、无刑期），三者不是同义词。
- 「冥律核心原则」五条中的「审判公正：有起诉→辩护→判决→上诉的完整程序」「刑罚适当」
  是现代法治概念投射，无古籍依据。
- 「孟婆 — 奈何桥边发放孟婆汤」——《玉历宝钞·孟婆神》章原文作醧忘台「居**第十殿**，
  冥王殿前**六桥**之外」。
