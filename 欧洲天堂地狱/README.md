**本目录原 README 有一处措辞已核实为误导**：「基督教 三合一：天堂 ←—炼狱—→ 地狱」
把炼狱画成与天堂、地狱并列的第三归宿。炼狱是**确定得救者**的过渡净化处所
（《天主教教理》1030-1031），不是第三种结局；且新教明确否定炼狱
（《奥格斯堡信条辩护》、《三十九条》第 22 条），东正教亦无此教义。详见
`docs/lore-verification/verify-christian-cast.md` 第四节。
