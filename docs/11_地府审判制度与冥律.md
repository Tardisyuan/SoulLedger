>

地府的审判叙事，在**《玉历宝钞》**这部清代善书里有一个可查的形态：**逐殿叙述体**，
每殿写「某王司掌某大地狱，另设十六小地狱」＋「凡阳世犯某某者，推入此狱」＋劝善。

[维基文库《玉历宝钞》全文转录](https://zh.wikisource.org/zh-hans/%E7%8E%89%E6%AD%B7%E5%AF%B6%E9%88%94)

## 一、「冥律」这个词实际指什么

### 1.1 定位（更正后）

| 项目 | 内容 |
|------|------|
| 「冥律／阴律」 | **观念范畴**，非书名。指阴间法度／因果报应之律，见于笔记小说 |
| 《玉历宝钞》 | **一部具体的清代善书**（劝善书），逐殿叙述体，**无条款编号、无刑期年限、无「律」的形式** |
| 三者关系 | **不是同义词**。v1.1 把它们并列为「别称」是错的 |
| 「上位法：天律」 | **无出处**，是本系统借现代法律位阶概念的自撰设定 |
| 本项目实际所用 | 一套自撰的软件规则；数值化善恶的真实文化原型是**功过格**（见 §4） |

**《玉历宝钞》的版本状况需要说明**：无权威定本。多种题名并行（玉歷／玉歷寶鈔／
玉歷鈔傳警世／勸世文，另有改编本《閻王經》），道藏辑本收光绪十六年（1890）本，
小狱名用字各本歧异。**成书年代学界有两说**：传统说辽太平十年（1030）淡痴道人著、
勿迷道人 1098 刊行（此说出自清·李宗敏序）；学者**王见川**则认为很可能是李宗敏本人
乾隆甲寅（1794）所撰。⚠️ 王见川的论证本项目**只取得维基百科的转述，未核原著**，
故列为学界两说并存，不做取舍。所以「以《玉历宝钞》为准」这句话本身需要指明是哪一本。

### 1.2 颁布链条 — **v1.1 把方向写反了**

v1.1 写：「冥律据传由天庭颁布，玉帝审核后下达酆都大帝执行。」

《玉历宝钞·玉曆之緣起》章的实际链条是**自下而上**：

```
地藏王菩薩诞辰发悲愿
        │
        ▼
十殿閻君同声启答，提议「借有德行之人，令其入冥目睹，記述《玉曆》」
        │
        ▼
八月初三日，十王諸佛将所拟议奏呈玉皇大帝 —— 「帝曰：善哉！善哉！」
        │
        ▼
通行下界城隍、土地、门灶神鬼
```

即 **十殿阎君提案 → 地藏首肯 → 玉帝批准 → 颁行**。玉帝是**批准者**不是立法者；
发起方是**地府**不是天庭。而**酆都大帝在《玉历》全文中只出场一次**——「枉死城」章
开头那一句——**既不是执行者也不是受命者**。

「玉帝—紫微—酆都」的层级、酆都统辖十殿之说，是**后起的民间神谱整合**，且与东岳大帝
职司高度重叠、诸说互相冲突（有说东岳为尊、有说酆都为尊、有说地藏统十殿）。
**这里民间信仰没有权威定本，本文不做取舍。**

### 1.3 v1.1 所列四部「经典依据」的核对结果 — **四部里三部有问题**

| v1.1 所写 | 核对结果 |
|---|---|
| **《玉历宝钞》** | **书是真的，但不是法典**（见 §1.1）。清代（或宋辽，两说）**善书**，非道藏/大藏正典 |
| **《地藏十王经》** | **书名混用**。十殿体系的实际源头是《**佛說預修十王生七經**》（全称《閻羅王授記四眾逆修生七往生淨土經》，成都府大聖慈寺沙門**藏川**述，卍续藏 [X01 No. 21](https://cbetaonline.dila.edu.tw/zh/X0021)）。另有《佛說地藏菩薩發心因緣十王經》（[X01 No. 20](https://cbetaonline.dila.edu.tw/zh/X0020)），日本学者景耀《考信錄》卷四指其文体混入日语，判为**日本平安末～镰仓初的伪撰**。而《**地藏菩薩本願經**》（[T0412](https://cbetaonline.dila.edu.tw/T0412)）**根本不含十殿体系** |
| **《太上老君律》** | **不存在这部书**。正统道藏目录无此题名。最接近的真书是《**太上老君經律**》（一卷，道藏洞神部戒律类，南北朝），且它与《女青鬼律》《玄都律文》一样，是**在世修道者的教团戒律／科仪规程**，不是审判亡魂的法典——当作「冥律经典依据」是范畴错置 |
| **《太乙救苦天尊经》** | **题名不对，且功能相反**。真实经名为《[太上洞玄靈寶天尊說救苦妙經](https://ctext.org/wiki.pl?if=en&chapter=266172)》与《太一救苦護身妙經》，是道教**度亡赦罪**科仪的核心经典——**救度**，不是**定罪**。列为「审判依据」是方向性错误 |

> **这一条与埃及「四十二判官」那次是同一层级的事**：《太上老君律》是**凭空造出的一个
> 权威**。差别只在于 42 判官是**名单**造假，本文 v1.1 是**框架**造假，后者更难被发现，
> 因为每个词单看都是真的。

### 1.4 基本原则 — 逐条标注依据

| 原则 | 依据状况 |
|---|---|
| **因果报应**：善有善报，恶有恶报 | ✅ 佛教业报观，成立 |
| **功过相抵**：善行可减轻恶行刑罚 | ✅ **有一手依据**。《玉历》一殿原文：「凡勾到**功过两平**之男妇，送交第十殿发放仍投人世」 |
| **寿数既定**：寿命由生死簿注定 | ✅ **有一手依据**。《玉历》一殿「专司人间寿夭生死册籍」 |
| ~~**审判公正**：有起诉、辩护、判决、上诉的完整程序~~ | ❌ **现代法治概念投射**，民间叙事中无此程序。作为软件设定保留，不作史实 |
| ~~**刑罚适当**：刑罚与罪行相匹配~~ | ❌ 同上。《玉历》的罪—狱对应是列举式的，不是「罪刑相当」原则 |

## 二、审判机构体系

### 2.1 审判机构层级

```
         ┌─────────────────┐
         │    天庭（玉帝）  │  ← 批准者（非立法者，见 §1.2）
         └────────┬────────┘
                  ▲ 奏呈批准
                  │
         ┌────────┴────────┐
         │    十殿阎王      │  ← 提案方 + 实质审判权
         └────────┬────────┘
                  │
                  ▼
         ┌─────────────────┐
         │    判官 / 功曹    │  ← 协助审理、文书记录
         └────────┬────────┘
                  │
                  ▼
         ┌─────────────────┐
         │   地方城隍       │  ← 初审/地方受理
         └─────────────────┘

酆都大帝：《玉历》全文只出场一次（枉死城章），不在这条链上。
          「酆都统辖十殿」属后起民间神谱整合，与东岳大帝说、地藏统十殿说并存冲突。
```

> **依据分级**：十殿—判官—功曹—城隍的层级在民间叙事里大体成立；
> 「天庭为上位法来源」是 v1.1 编的，已按《玉历·缘起》改为「奏呈批准」方向。

### 2.2 各殿审判分工（依《玉历宝钞》原文更正）

> **v1.1 的这张表自称依《玉历宝钞》，实际有 4 处与原文直接冲突（二、四、六、八殿）
> ——那是一条假引用。** 《玉历》的实际 schema 是：**一殿孽镜台（无大地狱）→
> 二至九殿各领一座「大地狱」＋十六小地狱 → 十殿六桥＋转劫所（无大地狱）**。
> v1.1 把小地狱、别名、乃至无据的名字与大地狱并列了。

| 殿位 | 阎王 | 《玉历》原文的大地狱 | 审判范围（《玉历》罪目） | v1.1 的错处 |
|------|------|---------|---------|---|
| 第一殿 | 秦广王 | **无大地狱**；殿右设**孽镜台**（「臺高一丈，鏡大十圍…上橫七字曰：孽鏡臺前無好人」） | 专司人间寿夭生死册籍 | — |
| 第二殿 | 楚江王 | **活大地狱**（又名「剥衣亭寒冰地狱」） | 拐骗少年男女、欺占他人财物、损坏人耳目手足 | ❌ 写作「剥衣亭、刀林地狱」——把**别名拆成了两个狱**，且「刀林」无据 |
| 第三殿 | 宋帝王 | **黑绳大地狱** | 忤逆尊长、教唆兴讼、背恩失节 | ⚠️ 多出一个无据的「剥皮地狱」 |
| 第四殿 | 五官王 | **合大地狱** | 抗粮赖租、交易欺诈 | ❌ 写作「秤钩地狱、血池地狱」 |
| 第五殿 | 阎罗王 | **叫唤大地狱**；**望乡台**在此殿 | 前殿解到之重犯 | ⚠️「诛心」是其十六小狱之一，非并列大狱 |
| 第六殿 | 卞城王 | **大叫唤大地狱** | 怨天尤地、偷窃神佛装塑法身内藏、不敬惜字纸经书 | ❌ 写作「沸汤地狱」 |
| 第七殿 | 泰山王 | **热恼大地狱** | 取骸合药、离散骨肉 | ✅ |
| 第八殿 | 都市王 | **大热恼大地狱** | **不孝**（亲存不养、亲殁不葬） | ❌ 写作「热恼闷锅地狱」；且「都市」不是「市集/商人」之意 |
| 第九殿 | 平等王 | **阿鼻大地狱** | 杀人放火、制毒等极恶 | ✅ |
| 第十殿 | 转轮王 | **无大地狱**；设**六桥**（金、银、玉、石、木板、**奈何**）＋**转劫所** | 核定投生去向 | — |

> **一处必须记录的真实分歧**：**八殿与九殿的王在不同文本里互换**。《佛说预修十王生七经》
> 与道教典籍常作「八殿平等王、九殿都市王」，《玉历宝钞》相反。本项目采《玉历》一系
> 并无问题，但不应写成唯一答案。
> 另外《十王经》的十王是**与七七斋期绑定**的时间表（一七至七七、百日、一年、三年），
> 《玉历》的十殿是**空间化的十座衙门**。本项目建的是后者。

## 三、审判流程

> ### ⚠️ 本节整节是**本系统自撰的软件流程**，不是史实
>
> 下面这套「立案登记／起诉／开庭／质证／一审／量刑／上诉／刑满释放」**完全是现代刑事
> 诉讼流程的投射**。民间地府叙事里没有这套程序：《玉历宝钞》是逐殿叙述体，亡魂被
> 「解到」某殿、按罪目「推入」某狱，没有起诉方、没有辩护、没有审级。
>
> 保留它是因为本项目要建的是一个**审批工作流系统**，需要一条可实现的流程。
> **但不要把它当作可引证的传统。** 需要有文献根据的流程时，用的是
> 「**十殿逐殿解送 ＋ 七七斋期**」（《玉历宝钞》一手文本；《十王经》的七七时间表）。

### 3.1 完整审判流程（系统自撰）

```
亡魂进入酆都城
        │
        ▼
【第一步：立案登记】
城隍提交案件 → 六案功曹录入 → 创建案件档案
        │
        ▼
【第二步：初步审查】
崔珏核查生死簿 → 核实生平记录 → 确认罪行清单
        │
        ▼
【第三步：起诉】
由六曹之一（通常为鬼曹）提出起诉 → 列明罪状
        │
        ▼
【第四步：分配审判殿】
根据罪行类型分配至对应殿位（初判殿或复审殿）
        │
        ▼
【第五步：开庭审判】
阎王审阅案卷 → 亡魂陈述 → 证人作证 → 证据质证
        │
        ▼
【第六步：一审判决】
判决结果：guilty（定罪）/ innocent（无罪）/ partial（部分成立）
        │
        ├─── 无罪 → 直接投胎
        │
        └─── 有罪 → 量刑
        │
        ▼
【第七步：量刑】
根据冥律对应条款 → 决定刑罚类型 → 分配地狱层数
        │
        ▼
【第八步：上诉（可选）】
不服判决 → 向上一级阎王申诉 → 魏征核查 → 重新审理
        │
        ▼
【第九步：刑罚执行】
分配至对应地狱 → 执行刑罚 → 记录服刑进度
        │
        ▼
【第十步：刑满释放】
刑罚执行完毕 → 释放至轮回殿
        │
        ▼
【第十一步：最终裁定】
转轮王核定 → 决定投胎道别/身份
        │
        ▼
【第十二步：孟婆汤 + 投胎】
喝孟婆汤 → 发放转世批文 → 进入六道轮回
```

### 3.2 上诉制度（系统自撰）

| 上诉条件 | 说明 | 依据 |
|---------|------|---|
| 理由 | 冤屈、误判、证据不足 | 自撰 |
| 上诉次数 | 通常最多 3 次 | **查无出处**，是发明的数字 |
| 上诉路径 | 本殿阎王 → 上一殿阎王 → 酆都大帝 | **查无出处**；且酆都大帝在《玉历》中不参与审判 |
| 审核机构 | 魏征（察查司） | 「察查司」**不是古籍职名**：它不在城隍庙二十四司、也不在北京东岳庙七十六司名录中；《西游记》里的魏征是**活着的人间丞相**，写信托付崔珏，并非冥司判官。见 `docs/02_地府人物详解.md` §四 |
| 改判条件 | 证据确证原判有误 | 自撰 |

### 3.3 特殊情况审理

**直接投胎（不经各殿）**：
- 无罪之人（生平无大恶）—— ✅ 《玉历》一殿有「善人径投」之说
- 冤死但寿数已尽 —— ⚠️ 见 `docs/10_枉死城详解.md`，该篇的核心前提被《玉历》原文驳斥
- ~~大善人（善行积分 ≥ 500）~~ —— ❌ **这个数字是发明的**，无任何出处。作为系统阈值可用，
  但不要写成传统设定

**直接入阿鼻地狱（不经各殿）**：
- 五逆（杀父、杀母、杀阿罗汉、出佛身血、破和合僧）—— ✅ **五逆名单正确**
- 诽谤正法且不知悔改 —— ✅ 见于佛教文献
- ⚠️ **术语更正**：v1.1 写作「上品五逆十恶」。「五逆」与「十恶三品」是**两个独立范畴**，
  缝成一个词在术语上不成立

## 四、罚则与功德 — **v1.1 两张表都挂错了名字**

### 4.1 「十恶」这个标题下曾列的六条，不是十恶

**佛教「十恶」＝十不善业道，是一份定数十条的名单**：
身三 **杀生、偷盗、邪淫**；口四 **妄语、两舌、恶口、绮语**；意三 **贪欲、瞋恚、邪见**。
（[十恶(佛教) — 维基百科](https://zh.wikipedia.org/zh-hans/%E5%8D%81%E6%81%B6_(%E4%BD%9B%E6%95%99))；
[十善业道经](https://zh.wikipedia.org/zh-hans/%E5%8D%81%E5%96%84%E4%B8%9A%E9%81%93%E7%BB%8F)；
杨曾文〈以十善为中心的佛教因果报应论〉—— 均为百科／学者文章转载，非一手经文）

v1.1 那六条里，杀生、偷盗、邪淫、妄语、邪见属十恶（5 条），
**「饮酒」根本不在十恶之内**——饮酒是**五戒**的第五戒（遮戒）。所以这六条的真实身份是
**「五戒＋邪见」的通俗合并**（杀盗淫妄酒 ＋ 邪见），不是十恶的前六条。

**因此曾入库的 note「缺四条」是错的**：若真要凑十恶，缺的是**五条**
（两舌、恶口、绮语、贪欲、瞋恚），并且要**去掉一条不该在的**（饮酒）。
本文档不补这五条——补齐等于把一份接错结构的名单做得更像真的。

**同名混用的另一个陷阱**：「十恶」还有第二个意思，即**唐律十恶**
（《唐律疏議·卷第一·名例律》逐字：「一曰謀反。二曰謀大逆。三曰謀叛。四曰惡逆。
五曰不道。六曰大不敬。七曰不孝。八曰不睦。九曰不義。十曰內亂。」——
[维基文库](https://zh.wikisource.org/zh-hant/%E5%94%90%E5%BE%8B%E7%96%8F%E8%AD%B0/%E5%8D%B7%E7%AC%AC%E4%B8%80)
／[ctext](https://ctext.org/wiki.pl?if=en&res=541794)，**一手**）。那是**世俗帝国刑律**中
「常赦所不原」的加重罪类（十恶不赦），与佛教十恶只是同名，内容毫无重叠。
v1.1 用「十恶」作标题填佛教内容，却把整套包装成唐律式的成文法外壳——两个「十恶」被混为一谈。

**《玉历宝钞》真正的罪—狱对应长什么样**（如需有据的数据，抄这个）：
逐殿列举式，例如二殿「拐骗少年男女、欺占他人财物、损坏人耳目手足…者，推入此狱」，
并配十六小地狱（二殿逐字示范：黑雲沙、糞尿泥、五叉、饑餓、燋渴、膿血、銅斧、多銅斧、
鐵鎧、𧉞量、雞、灰河、斫截、**劍葉**、狐狼、**寒冰**）。**没有条款编号，没有刑期年数。**

### 4.2 「十善」这个标题下曾列的七条，一条都不是十善

**佛教「十善」＝十恶的反面**（不杀生、不偷盗、不邪淫、不妄语、不两舌、不恶口、
不绮语、不贪欲、不瞋恚、不邪见）。

v1.1 列的「孝养父母 / 戒杀放生 / 布施行善 / 诚信不欺 / 救死扶伤 / 敬奉神明 /
持守五戒」——这是**善书／功过格**风格的德目表，**与十善业道无一条对应**。
「缺三条」这个说法无从谈起：不是缺三条，是整张表挂错了名字。

**那些数值（+100 / +50 / +40 / +30 / +10 / +80）无出处，是发明的。**

### 4.3 数值化善恶的真实文化原型是**功过格**，不是任何「冥律」

这是本次核实中唯一一条「设计意图有真文献支撑、只是挂错了牌子」的发现。

**《太微仙君功過格》**（金大定十一年／1171 序，收正统道藏，
[维基文库全文](https://zh.wikisource.org/zh-hans/%E5%A4%AA%E5%BE%AE%E4%BB%99%E5%90%9B%E5%8A%9F%E9%81%8E%E6%A0%BC)，
**一手**）的实际形态：

- **功格四门**：救濟門(12)、教典門(7)、焚修門(5)、用事門(12)；
  **過律四門**：不仁門(15)、不善門(8)、不義門(10)、不軌門(6)
- 逐字数值示例：「救重疾一人為**十功**，小疾一人為**五功**」「救一人刑死性命為**百功**」
  「賑濟鰥寡孤獨窮民**百錢為一功**」
- 记账法：「**明書日月，自記功過，一月一小比，一年一大比**」

另见袁黃《了凡四訓》（1569 起行功过格）一系。

> **两点必须随之说明**：
> 1. **功过格是活人自己记的账，不是审判亡魂的刑法典。** 本项目把它用作判决依据，
>    是一次**有意的挪用**，应当写明，不要说成「地府依此定罪」。
> 2. **非同质性**：《文昌帝君功過格》的凡例明言，一百次布施之功**不能**抵一百次
>    致人死命之过。本项目现有的线性加减模型允许这种抵销，与该传统不合。

### 4.4 功过相抵

## 五、证据制度（**整节为系统自撰**）

> 下表的「证据类型／可信度分级」是**现代证据法的投射**，民间叙事中没有这套分级。
> 尤其「三生石显现＝辅助参考」——三生石典出唐·袁郊《甘泽谣·圆观》（宋·苏轼
> 《僧圆泽传》改称圆泽），实景在**杭州天竺**，是阳间景物，与冥界审判无关，
> 更不是一种证据（见 `docs/09_忘川河水系与奈何桥.md` §三）。
>
> 有一手依据的只有一条：**生死簿**（《玉历》一殿「专司人间寿夭生死册籍」）。

### 5.1 证据类型（系统自撰）

| 证据类型 | 来源 | 可信度 | 依据 |
|---------|------|--------|---|
| 生死簿记录 | 崔珏/功曹实时记录 | 最高 | ✅ 生死簿见《玉历》一殿；崔珏掌生死簿见《西游记》第十回 |
| 证人证词 | 城隍/土地公/日游神/夜游神 | 高 | 自撰 |
| 现场勘查 | 黑白无常/牛头马面 | 中高 | 自撰 |
| 悔过书 | 亡魂自述 | 参考 | 自撰（《玉历》有悔过日期之说，但非「证据」） |
| 三生石显现 | 前世记忆 | 辅助参考 | ❌ 张冠李戴，见上 |

### 5.2 证据采集（系统自撰）

- **生前行为记录**：由日游神/夜游神实时记录
- **临终遗言**：由土地公转交
- **遗物佐证**：烧纸/祭祀记录
- **目击证人**：相关亡魂/神祇
