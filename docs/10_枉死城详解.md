# 枉死城详解

> ## ⚠️ v2.0 的核心更正：**本文档 v1.0 整篇建立的，正是《玉历宝钞》专章要驳斥的那个说法**
>
> 《玉历宝钞》有独立的《枉死城》章，全文由**酆都大帝**说出，开篇即是：
>
> > 「枉死城，係環繞本殿之右。**世人誤以為，凡受傷冤枉死鬼，悉皆歸入此城之說，
> > 遍傳為實。**」須知，屈死者，豈再加以無辜之苦乎？
>
> **也就是说，这一章存在的目的，就是要驳斥「凡枉死者一概收入枉死城」这个流行说法。**
> 而 v1.0 通篇建立的就是那个被驳斥的说法：五大类枉死、四个必要条件、按死因分区关押、
> 关押至原定寿命终结。原文的反问「屈死者，岂再加以无辜之苦乎」，正对着 v1.0 的
> 「寿数等待制」。
>
> 另有两处 v1.0 的具体错误：
>
> - **「地藏王菩萨所创建／最高管辖者」——一手文本无此说。** 地藏在《玉历》里出现于
>   《玉曆之緣起》章（他在诞辰上请十王编《玉历》劝世），**与枉死城无关**。
>   「地藏创枉死城」本项目只在百度百科等二手转述中见到，**未找到一手依据**。
> - **位置写错**：原文作「**環繞本殿之右**」，是贴着后段某殿，**不是**「酆都城外，
>   靠近莲花台附近」。⚠️ 「本殿」究竟指九殿还是十殿，转录中章节界限不明确，
>   本项目两次抓取得到不同答案，**故存疑不下结论**；可确定的只有「贴着后段某殿之右」，
>   以及**绝不是**酆都城外。（「莲花台」本身还是净土宗被挪用的词，见
>   [`06_地府十三站详解.md`](06_地府十三站详解.md)。）
>
> **v2.0 的处理**：保留全篇作为**本项目的产品设定**（`disposition` 需要一个收容非命
> 死亡亡魂的状态），但把它与一手文本的关系写清楚——**这是一个被《玉历》点名驳斥的
> 流行说法，不是《玉历》的记载。**
>
> 依据：[维基文库《玉历宝钞·枉死城》](https://zh.wikisource.org/zh-hans/%E7%8E%89%E6%AD%B7%E5%AF%B6%E9%88%94)
> （一手转录）；`docs/lore-verification/verify-cn-structure.md` §2.4(e)。

枉死城在**现代通俗叙事**中，是地府专门关押"枉死之人"魂魄的场所。以下为本项目采用的
产品设定；与一手文本的出入已逐节标注。

---

## 一、枉死城的定位

### 1.1 地理位置

| 项目 | 产品设定 | 一手文本 |
|------|------|---|
| 创建者 | 地藏王菩萨 | ❌ **《玉历》无此说**。该章由酆都大帝说出；地藏在《玉历》里只出现于缘起章，与枉死城无关 |
| 性质 | 类似于阳间的监狱 | ⚠️ 原文的立场恰恰是「屈死者，岂再加以无辜之苦乎」 |
| 位置 | 酆都城外，靠近莲花台附近 | ❌ 原文作「**環繞本殿之右**」。⚠️ 「本殿」指九殿还是十殿**存疑**；可确定的只有它贴着后段某殿，**绝不是**酆都城外 |
| 特点 | 任何人鬼神都无法私自靠近 | 产品设定，无出处 |

### 1.2 枉死城的性质

枉死城不同于十八层地狱：
- **十八层地狱**：关押因罪大恶极而应受刑罚的亡魂
- **枉死城**：关押本不该死但因各种原因提前死亡的人

> ⚠️ **注意**：「十八层地狱」本身也是与十殿竞争的另一套说法，且被《玉历》明文否定
> （见 [`04_地狱体系详解.md`](04_地狱体系详解.md) §二）。用它来给枉死城下定义，
> 是把两个都无一手支撑的东西互相定义。

> **核心原则（产品设定）**：人的寿命由天命注定（生死簿上写明），枉死之人虽有冤屈，但若非有大善大恶大冤在身，既不能立即升天，也不能直接打入地狱，只能暂时关押于枉死城。
>
> ⚠️ **「生死簿／寿数既定」有一手依据**（《玉历》一殿「专司人间寿夭生死册籍」）；
> **「一概关押至原定寿命终结」没有**，且与《枉死城》章的立场相反。

## 二、枉死城的囚犯来源（**整节为产品设定，无一手依据**）

> ⚠️ 下面的「四个必要条件」与「五大类分区」是本文档 v1.0 自撰的分类，一手文本中不存在。
> 《玉历宝钞·枉死城》章不作分类，它做的是**否定**「凡枉死者一概收入此城」。

### 2.1 进入枉死城的条件（产品设定）

**必须同时满足以下条件：**
1. 死因属于"非命"（非自然死亡）
2. 死者生前无大善（不能立即升天）
3. 死者生前无大恶（不能直接入地狱受刑）
4. 死者生前无重大冤情可以伸冤（不能立即转世）

### 2.2 枉死类型分类

#### 第一类：意外身亡

| 意外类型 | 说明 |
|---------|------|
| 交通事故 | 车祸、航空事故、船只倾覆 |
| 工伤事故 | 建筑事故、矿难、工厂事故 |
| 自然灾害 | 地震、洪水、台风、雷电 |
| 火灾 | 火灾中的遇难者 |
| 溺水 | 落水、游泳事故 |
| 触电 | 电击死亡 |
| 食物中毒 | 毒物中毒死亡 |

#### 第二类：刑事被害

| 案件类型 | 说明 |
|---------|------|
| 被谋杀 | 他人故意杀害 |
| 被伤害致死 | 斗殴、伤害致人死亡 |
| 被拐卖后死亡 | 被拐卖过程中死亡 |
| 被诈骗后自杀 | 因被骗导致死亡 |
| 医疗事故 | 医疗过失致人死亡 |

#### 第三类：自杀

| 自杀方式 | 特殊情况 |
|---------|---------|
| 因病痛自杀 | 非自愿结束生命 |
| 因债务自杀 | 经济压力导致 |
| 因情自杀 | 感情问题导致 |
| 厌世自杀 | 对生活绝望 |
| 殉情/殉节 | 为情或某种信念而死 |

> ⚠️ **v1.0 此处写「自杀在十八层地狱中有专门一层（第十四层：枉死地狱）」——这份十八层
> 名单本身出处待考**（百科系于《水陆全图》，本项目未找到一手转录；见
> [`04_地狱体系详解.md`](04_地狱体系详解.md) §二）。
> **《玉历宝钞》讲自尽者的处置在第一殿，作饿鬼道／阿鼻大地狱**，且原文根本没有那份
> 十八层名单。以下保留为产品设定。

#### 第四类：战争死亡

| 类型 | 说明 |
|------|------|
| 战场死亡 | 古代战争中的士兵 |
| 屠杀遇难者 | 大规模屠杀的受害者 |
| 瘟疫死亡 | 疫病流行的死者 |

#### 第五类：其他特殊情况

| 类型 | 说明 |
|------|------|
| 难产死亡 | 产妇/婴儿死亡 |
| 冻死/饿死 | 因贫困而死 |
| 死刑犯 | 被处决的犯人 |
| 客死他乡 | 无人认领的亡魂 |

## 三、枉死城的管理

### 3.1 管辖神祇

| 神祇 | 产品设定中的职责 | 依据 |
|------|------|---|
| **地藏王菩萨** | 枉死城的创建者和最高管辖者 | ❌ **一手文本无此说，已删除该断言**。《玉历·枉死城》章由**酆都大帝**说出；地藏在《玉历》里只出现于缘起章。「地藏创枉死城」仅见于百度百科等二手转述 |
| **谛听** | 协助地藏王辨别亡魂生前善恶 | ⚠️ 谛听出自《西游记》及民间传说，**非佛教原典**；佛教传统中地藏一般为寂静相，无坐骑造像 |
| **各地方城隍** | 押送本地枉死亡魂 | 产品设定 |

### 3.2 枉死城内部结构（**本项目自撰，非民间传说**）

> ⚠️ v1.0 写「根据民间传说，枉死城内部有分区」。**没有这样的民间传说被找到**——
> 下面这套按死因分区的结构是本文档自己设计的。改称「产品设定」。

```
枉死城
├── 意外死亡区（交通事故、工伤、自然灾害等）
├── 被害死亡区（谋杀、伤害致死等）
├── 自杀死亡区（各类自杀者）
├── 战争死亡区（战场亡魂、屠杀遇难者）
├── 无人认领区（客死他乡无人收尸者）
└── 特殊冤魂区（大冤未申者）
```

### 3.3 管理制度

| 规则 | 说明 |
|------|------|
| 寿数等待制 | 亡魂必须关押至原定寿命终结才能离开 |
| 不得私自离开 | 枉死城有重兵把守，无法私自逃脱 |
| 冤情申诉 | 有冤情的亡魂可向城隍或地藏王申诉 |
| 度化超拔 | 地藏王菩萨定期在莲花台度化枉死城亡魂 |

## 四、枉死城的出口

### 4.1 正常释放

当枉死亡魂的**原定寿命**到期时，可以离开枉死城，进入正常的地府审判流程：

```
枉死城关押（原定寿命剩余时间）
        │
        ▼
寿数到期 → 释放出城
        │
        ▼
进入正常审判流程（第一殿秦广王开始）
        │
        ▼
根据善恶审判 → 投胎转世
```

### 4.2 冤情申诉通道

**有重大冤情的枉死亡魂可以申诉**：

| 申诉方式 | 说明 |
|---------|------|
| 向城隍申诉 | 地方层面调查核实 |
| 向地藏王菩萨申诉 | 最高层面受理 |
| 托梦告知阳间亲人 | 通过活人代为申冤 |
| 请道士/僧人做法事 | 超度、申冤 |

**申诉成功的结果**：
- 若确属冤死且冤情重大 → 可提前释放
- 冤魂可化为厉鬼（但会受罚）
- 冤情转达天庭/地藏王 → 从重处理加害者

### 4.3 度化超拔

地藏王菩萨定期在**莲花台**（第十二站）度化枉死城亡魂：
- 给亡魂一个赎罪和向善的机会
- 引导亡魂放下怨恨
- 优先超拔怨气较轻的亡魂

## 五、枉死城与十八层地狱的区别

| 对比项 | 枉死城 | 十八层地狱 |
|--------|--------|-----------|
| **关押对象** | 本不该死而死的亡魂 | 罪大恶极应受刑罚的亡魂 |
| **管理者** | 地藏王菩萨 | 十殿阎王 |
| **性质** | 临时关押所 | 刑罚执行场所 |
| **关押时长** | 至原定寿命终结 | 依罪行轻重而定 |
| **痛苦程度** | 相对较轻（主要是困禁） | 极重（各种酷刑） |
| **出狱条件** | 寿数到期/申冤成功/超度 | 刑满/减刑/特赦 |
| **入狱原因** | 非命死亡但非大善大恶 | 犯十恶五逆等重罪 |

## 六、枉死城在管理系统中的建模

### 6.1 核心数据表

#### 枉死记录表 (wrongful_death_record)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| soul_id | BIGINT FK | 亡魂ID |
| death_cause | ENUM | 死亡原因（意外/被害/自杀/战争/其他） |
| wrongful_death_type | VARCHAR(50) | 枉死类型详细 |
| original_death_date | DATE | 实际死亡日期 |
| original_lifespan | DATE | 原定寿命截止日期 |
| remaining_years | INT | 剩余年数 |
| imprisonment_date | DATETIME | 入城日期 |
|冤情等级 | ENUM | 'none','minor','major','severe' |
| appeal_status | ENUM | 'none','filed','in_review','resolved' |
| release_date | DATE | 释放日期（寿数到期） |
| release_status | ENUM | 'imprisoned','released','transferred' |

### 6.2 业务流程

```
发现枉死亡魂
        │
        ▼
城隍登记 → 录入枉死城系统
        │
        ▼
分配区域（意外/被害/自杀/战争/其他）
        │
        ▼
寿数到期？
        │
        ├─ 是 → 进入正常审判流程
        │
        └─ 否 → 继续关押
                │
                ▼
有冤情申诉？
        │
        ├─ 是 → 审核 → 属实则提前释放/超度
        │
        └─ 否 → 继续关押至寿数到期
```

### 6.3 枉死城与系统模块的对应

| 枉死城元素 | 系统管理概念 |
|-----------|-------------|
| 关押区域 | 分类存储/状态隔离 |
| 寿数等待制 | 时间锁定/条件释放 |
| 冤情申诉 | 客服工单/申诉流程 |
| 度化超拔 | 批量处理/特殊豁免 |
| 释放出城 | 状态变更/流程流转 |
