## 2. 逐项核实

### 2.1 冥律条文（重点）

#### (a) 「缺的四条／三条」是什么？——问题问错了

**§4.1 那六条不是「十恶」的前六条。** 佛教「十恶」＝十不善业道，定数为：
身三 **杀生、偷盗、邪淫**；口四 **妄语、两舌、恶口、绮语**；意三 **贪欲、瞋恚、邪见**。
`docs/11` 列的六条中，**杀生、偷盗、邪淫、妄语、邪见** 属十恶（5 条），**「饮酒」根本不在十恶之内**——饮酒是**五戒**的第五戒（遮戒），不是十恶。所以：

- 真正缺的是 **五条**：两舌、恶口、绮语、贪欲、瞋恚
- 并且多出一条不该在的：**饮酒**

现有 note（「缺四条」）本身就是错的。
来源：[十恶 (佛教) — 维基百科](https://zh.wikipedia.org/zh-hans/%E5%8D%81%E6%81%B6_(%E4%BD%9B%E6%95%99))（c 百科）；[十善业道经 — 维基百科](https://zh.wikipedia.org/zh-hans/%E5%8D%81%E5%96%84%E4%B8%9A%E9%81%93%E7%BB%8F)（c）；杨曾文〈以十善为中心的佛教因果报应论〉[tibet3.com](https://www.tibet3.com/wenhua/whcl/2020-07/16/content_300179494.html)（b 学者文章转载）

**§4.2 那七条不是「十善」的前七条，一条都不是。** 佛教「十善」＝十恶的反面（不杀生、不偷盗、不邪淫、不妄语、不两舌、不恶口、不绮语、不贪欲、不瞋恚、不邪见）。`docs/11` 列的是「孝养父母 / 戒杀放生 / 布施行善 / 诚信不欺 / 救死扶伤 / 敬奉神明 / 持守五戒」——这是**善书／功过格**风格的德目表，与十善业道**不是同一份名单**。「缺三条」这个说法无从谈起：不是缺三条，是整张表挂错了名字。

#### (b) 「十恶」这个词还有第二个意思，而且 `docs/11` 同时踩了

- 佛教十恶（十不善业道）＝上面那十条
- **唐律十恶**（《唐律疏議》**卷第一·名例律**，逐字：「一曰謀反。二曰謀大逆。三曰謀叛。四曰惡逆。五曰不道。六曰大不敬。七曰不孝。八曰不睦。九曰不義。十曰內亂。」）—— 这是**世俗帝国刑律**中「常赦所不原」的加重罪类（十恶不赦），源头可上溯北齐律「重罪十条」，与佛教十恶只是同名，内容毫无重叠。核心关切是君权、宗法与丧祭秩序。
  一手：[维基文库《唐律疏議·卷第一》](https://zh.wikisource.org/zh-hant/%E5%94%90%E5%BE%8B%E7%96%8F%E8%AD%B0/%E5%8D%B7%E7%AC%AC%E4%B8%80)（**a**）、[ctext《唐律疏議》](https://ctext.org/wiki.pl?if=en&res=541794)（**a**）

`docs/11` 用「十恶」作标题却填佛教内容，同时把整套东西包装成「法律法规体系 / 条款编号 / 刑期年限」这种**唐律式的成文法**外壳。两个「十恶」被混为一谈。

#### (c) 民间地府信仰里有成文「冥律」吗？——没有

一手文本检验：**《玉历宝钞》（维基文库全文转录，(a) 一手转录）**的实际结构是：

```
玉曆之緣起 / 一殿 秦廣王 … 十殿 轉輪王 / 轉劫所 / 孟婆神 / 枉死城 /
血污池 / 山妖水怪 / 財癆鬼 / 當兵戰死 / 十八層地獄
```

即**逐殿叙述体**：每殿写「某王司掌某大地狱，另设十六小地狱」＋「凡阳世犯某某者，推入此狱」＋劝善（悔过日期、抄印传播此书的功德、免罪条件）。**没有条款编号，没有刑期年数，没有「律」的形式。** 它是善书（劝善书），不是法典。

**《玉历宝钞》真正的 schema 是（这可以直接拿来做数据模型）**：

```
一殿  秦廣王   —— 无小地狱，设【孽鏡臺】（「臺高一丈，鏡大十圍…上橫七字曰：孽鏡臺前無好人」）
二殿~九殿      —— 每殿：一座【大地獄】（縱廣五百由旬）+【十六小地獄】+ 罪目
十殿  轉輪王   —— 无小地狱，设【六橋】（金、銀、玉、石、木板、奈何）+【轉劫所】
附章           —— 轉劫所 / 孟婆神(醧忘臺) / 枉死城 / 血污池 / 山妖水怪 / 財癆鬼 / 當兵戰死 / 十八層地獄(辨正)
```

二殿十六小狱逐字（示范）：黑雲沙、糞尿泥、五叉、饑餓、燋渴、膿血、銅斧、多銅斧、鐵鎧、𧉞量、雞、灰河、斫截、**劍葉**、狐狼、**寒冰**。

**版本无权威定本**：多种题名并行（玉歷／玉歷寶鈔／玉歷鈔傳警世／勸世文，另有改编本《閻王經》），道藏辑本收光绪十六年（1890）本；小狱名用字各本歧异（如「𧉞量／豳量」）。一贯道与部分佛教立场的教内文章更直指其为伪造。**「以《玉历宝钞》为准」这句话本身就需要说明是哪一本。**

来源：[维基文库《玉历宝钞》](https://zh.wikisource.org/zh-hans/%E7%8E%89%E6%AD%B7%E5%AF%B6%E9%88%94)（**a 一手转录**）；[ctext《玉歷鈔傳警世》异本](https://ctext.org/wiki.pl?if=gb&chapter=753101)（**a**）

结论：**《玉历宝钞》那类劝善书的「罪—狱对应表」，正是任务描述里猜测的那一种**；「成文冥律 + 条款编号 + 最短/最长刑期」是本项目自己加的现代法制外壳。

`docs/11` §1.2 把《冥律》说成「由天庭颁布，玉帝审核后下达酆都大帝执行」——这个颁布链条**在《玉历宝钞》原文里不存在**：原文的缘起是**地藏王菩萨**在诞辰上请十王编《玉历》劝世，再由**酆都大帝**转呈，不是玉帝立法下发。

#### (d) `docs/11` §1.2 引的四部「经典依据」——**四部里三部有问题**

#### (d2) 「冥律」这个词真吗？——词真，书假

- **冥律／阴律** 在笔记小说（《夢溪筆談》《閱微草堂筆記》等）中确为常用语，指「阴间的法度／因果报应之律」，是**观念范畴**，**不是一部书**。[汉典「陰律」](https://zdic.net/hans/%E9%99%B0%E5%BE%8B)（c）
- **不存在**任何题名《冥律》且含编号条文的传世文本。检索未见任何目录著录。
- 唯一大量以「阴律」为书名的是**《陰律無情》**（署上官玉华，自述 2012 壬辰年成书，扶乩／自述见闻类）——**当代作品**。若项目的「冥律」观念其实源自网络流传的这本，那是 2012 年的东西。[UDN 转载](https://blog.udn.com/yoyoman/10786539)（d）

#### (d3) 十王体系的学术定论（Teiser）

Stephen F. Teiser, *The Scripture on the Ten Kings and the Making of Purgatory in Medieval Chinese Buddhism*, University of Hawai'i Press, 1994。据出版方与两篇同行书评：《十王經》是**中土撰述的疑伪经**，非印度译典；9–10 世纪中国已形成结构完整的「炼狱」——亡者依次过**十个法庭**，每庭一王如同**地方官僚衙门**；其本质是**印度业报观 ＋ 中国官僚制**的合成，并与**七七斋**丧仪绑定。

#### (d4) 「天庭颁布 → 玉帝审核 → 酆都大帝执行」——**方向被倒过来了**

《玉历》缘起章的实际链条是**自下而上**：

> 地藏王菩薩发悲愿 → **十殿閻君**同声启答，提议「借有德行之人，令其入冥目睹，記述《玉曆》」 → 八月初三日，**十王諸佛**将所拟议**奏呈玉皇大帝**，「帝曰：善哉！善哉！」 → 通行下界城隍、土地、门灶神鬼

即 **十殿阎君提案 → 地藏首肯 → 玉帝批准 → 颁行**。玉帝是**批准者**不是立法者；发起方是**地府**不是天庭。
而**酆都大帝在《玉历》全文中只出场一次**——就是「枉死城」那一句——**既不是执行者也不是受命者**。

「玉帝—紫微—酆都」的层级、酆都统辖十殿之说，是**后起的民间神谱整合**，且与东岳大帝职司高度重叠、诸说互相冲突（有说东岳为尊、有说酆都为尊、有说地藏统十殿）。**这里民间信仰没有权威定本。**

#### (e0) 功过格：这才是「给行为标数值」的真传统（一手数值可查）

**《太微仙君功過格》**（金大定十一年/1171 序，正统道藏）：
- **功格四门**：救濟門(12)、教典門(7)、焚修門(5)、用事門(12)；**過律四門**：不仁門(15)、不善門(8)、不義門(10)、不軌門(6)
- 逐字数值示例：「救重疾一人為**十功**，小疾一人為**五功**」「救一人刑死性命為**百功**」「賑濟鰥寡孤獨窮民**百錢為一功**」
- 记账法：「**明書日月，自記功過，一月一小比，一年一大比**」

[维基文库《太微仙君功過格》全文](https://zh.wikisource.org/zh-hans/%E5%A4%AA%E5%BE%AE%E4%BB%99%E5%90%9B%E5%8A%9F%E9%81%8E%E6%A0%BC)（**a 一手**）；袁黃《了凡四訓》（1569 起行功过格）[维基](https://zh.wikipedia.org/zh-tw/%E4%BA%86%E5%87%A1%E5%9B%9B%E8%A8%93)（c）

→ **`孝养父母 +100 / 布施 +50` 的真实文化原型是功过格，不是任何「冥律」。** 这是本报告里唯一一条「项目的设计意图有真文献支撑、只是挂错了牌子」的发现。

#### (e) 但有两条 `docs/11` 的原则**是有一手依据的**（不要一起否掉）

- **功过相抵**：《玉历宝钞》一殿原文有「凡勾到**功过两平**之男妇，送交第十殿发放仍投人世」——功过比较确实是该体系的机制。
- **寿数既定 / 生死簿**：一殿「专司人间寿夭生死册籍」，成立。
- **积分制**（+100 / +50 …）：这个不属于冥律，属于**功过格**传统（《太微仙君功过格》《了凡四训》《太上感应篇》一系），那才是中国真正给具体善恶行为记数值的文类。挂错了出处，但数值化本身有传统可循。

### 2.2 地府十三站 — **判定：2017 年后的网络列表，无古籍依据**

（专项调查结论，来源与判据见下）

#### (b) 十八层地狱与十殿是什么关系？——**《玉历宝钞》自己否定「十八层」**

原文末章《十八層地獄》开宗明义：「**世人皆云，陰司只有『十八層地獄』之說，非也！**」——它给出的实际结构是 **八大地狱 × 十六小地狱 ＋ 血污池、枉死城等，合计 138 处**。

所以：
- 「十八层地狱」与「十殿」**不是同一套体系的两层**，是**两套来源不同、互相竞争的说法**；`docs/01`/`docs/04` 把二者并置成「十殿地狱 + 十八层地狱两套系统」，并让 `docs/06` 把「十八层地狱」当作行程的第 9/11 站，与所引权威直接冲突。
- `docs/01`/`docs/04` 那份 18 名（拔舌/剪刀/铁树/孽镜/蒸笼/铜柱/刀山/冰山/油锅/牛坑/石压/舂臼/血池/枉死/磔刑/火山/石磨/刀锯）**不是《十八泥犁经》的名单**。《十八泥犁经》（後漢·安世高譯）的十八狱全是**梵语音译**：光就居、居虚倅略、桑居都、楼、房卒、草乌卑次、都卢难旦、不卢半呼、乌竟都、泥卢都、乌略、乌满、乌藉、乌呼、须健居、末都干直呼、区通途、陈莫。
- `docs/01` 那句「每一层比前一层增苦二十倍，增寿一倍」**确实**出自《十八泥犁经》，但被嫁接到了另一份名单上——**拼接引用**。
- 那份通俗 18 名，百科普遍系于《水陆全图》（明清水陆画）。我**没有找到**该图的一手转录或学术研究来确认这一系名；只能说「二手转述一致，一手待考」。
- `docs/04` 第三层铁树地狱写「据《玉历宝钞》，此狱为离间罪者所设」——**《玉历宝钞》没有这份十八层名单**，此引用为伪。

来源：[十八层地狱 — 维基百科](https://zh.wikipedia.org/zh-hans/%E5%8D%81%E5%85%AB%E5%B1%82%E5%9C%B0%E7%8B%B1)（c）；[佛說十八泥犁經 — 维基文库](https://zh.wikisource.org/zh-hant/%E4%BD%9B%E8%AA%AA%E5%8D%81%E5%85%AB%E6%B3%A5%E7%8A%81%E7%B6%93)（**a**）；[维基文库《玉历宝钞》十八層地獄章](https://zh.wikisource.org/zh-hans/%E7%8E%89%E6%AD%B7%E5%AF%B6%E9%88%94)（**a**）

#### (c) 忘川 / 奈河 / 三途河 — 三个不同来源被 `docs/09` 当成同义词

- **奈河**：**有唐代一手依据**。唐·张读《宣室志》卷四：「此俗所谓奈河，其源出地府」，「其水皆血，而腥秽不可近」。清·顾炎武《山东考古录·辨奈河》记泰山蒿里山左有奈河、有桥曰奈河桥。另有民俗学解释：唐代吊丧口唱「奈何」，与「奈河」同音相涉。
- **忘川**：**查不到中国古籍作为冥河的用例**。通行的考据意见是它是希腊神话 **Lethe（Λήθη，「遗忘」）**的汉译名倒流进中文冥界叙事的产物。本项目自己的 seed 也印证了这一点——`忘川` 在库里挂的是**欧洲侧**的 `Lethe / 忘川河神`。
  ⚠️ 该判断我目前只找到二手转述（百科与知乎专栏），**未取得一手或学术论证**；zhihu.com/p/697225775〈忘川考〉抓取被 403 拦下。**列为「强烈存疑但未定谳」。**
- **三途河**：**是日本的 三途の川（Sanzu no Kawa）**。汉传「**三途/三涂**」指的是**三恶道**（火途地狱、血途畜生、刀途饿鬼），**不是一条河**。`docs/09` §1.2 把「三途」当作「渡河的三条路径」，是把汉传的三恶道概念误读成日本的渡河三濑（浅瀬/深淵/有橋渡）。
- `docs/09` §1.1「起源：唐代文献记载」——只对 **奈河** 成立，被张冠李戴到「忘川河」头上。

来源：[奈河 — 百度百科（引《宣室志》《山东考古录》）](https://baike.baidu.com/item/%E5%A5%88%E6%B2%B3/3521737)（c，但引文可溯）；[三途河 — 百度百科](https://baike.baidu.com/item/%E4%B8%89%E9%80%94%E6%B2%B3/2862634)（c）；[三途 — 佛学常见辞汇](http://m.fodizi.tw/f01/29710.html)（c）

#### (d) 奈何桥 / 孟婆亭 / 望乡台的**位置关系**——`docs/09` 的流程图与一手文本冲突

《玉历宝钞》一手文本：
- **孟婆神**「台居**第十殿**，冥王殿前**六桥**之外」，台名 **醧忘台**；六桥为「金、银、玉、石、木板、**奈何**等桥六座」。
  → **奈何桥是第十殿前六桥之一**，不是横跨忘川的独立三层桥；**孟婆台在十殿**，不在「奈何桥边」。
- **望乡台在第五殿**（「面如弓背，朝东西南三向……台高四十九丈」），且**只有恶鬼被押上台**，善人与功过两平者根本不上。

`docs/09` §5 流程图作「黄泉路→忘川河→奈何桥三层→望乡台→三生石→孟婆亭→进入酆都城开始审判」。这与《玉历》**次序完全相反**：望乡台在审判过程中（第五殿），孟婆在**全部审判之后**（第十殿）。仓库 seed 把望乡台放在 `DY_COURT_05_YANLUO` 的描述里、把孟婆汤放在第十殿——**seed 是对的，`docs/09` 是错的**。

「**奈何桥三层（红/玄黄/黑）**」：`docs/09` 自己已标注「属民间系统化演绎」——这个自我标注是诚实的，保留。但《玉历》的对应物是**六桥**（金银玉石木板奈何），不是三层，值得写明。

**三生石**：典故为唐·袁郊《甘泽谣·圆观》（宋·苏轼《僧圆泽传》改称**圆泽**，`docs/09` 用的是苏轼版名字），地点在**杭州天竺（今法镜寺西侧）**，是阳间实景。「奈何桥边的三生石，刻『早登彼岸』四字」是**现代网络叙事**，与李源圆观典故无关。`docs/09` §2.4/§3 把两者合并了。
学术参考：严春华〈三生石故事考辨〉[台大佛学数位图书馆 PDF](https://buddhism.lib.ntu.edu.tw/FULLTEXT/JR-MAG/mag148518.pdf)（**b 学术**）；[三生石(杭州) — 维基百科](https://zh.wikipedia.org/zh-hans/%E4%B8%89%E7%94%9F%E7%9F%B3_(%E6%9D%AD%E5%B7%9E))（c）

**彼岸花开在黄泉路**（`docs/06` 第二站）：**这是日本的说法**。石蒜（曼珠沙华）近彼岸（秋分）开、生于墓地，在日本被附会为死亡之花；**中国传统中无此说**，石蒜反因色艳而用作喜庆花。该联想经现代网络传入中文。属于**明确的外来窜入**。

#### (e) 枉死城 — **`docs/10` 与一手文本正面冲突**

《玉历宝钞》有独立的《枉死城》章，全文由**酆都大帝**说出，开篇即是：

> 「枉死城，係環繞本殿之右。**世人誤以為，凡受傷冤枉死鬼，悉皆歸入此城之說，遍傳為實。**」須知，屈死者，豈再加以無辜之苦乎？

也就是说，**这一章存在的目的，正是要驳斥「凡枉死者一概收入枉死城」这个流行说法**。而 `docs/10` 通篇建立的就是那个被驳斥的说法：五大类枉死、四个必要条件、按死因分区关押、关押至原定寿命终结。

另外：
- **「地藏王菩萨所创建 / 最高管辖者」**：《玉历宝钞》原文中**没有**这个说法。地藏在原文里出现于《玉曆之緣起》——他在诞辰上请十王编《玉历》劝世——与枉死城无关。「地藏创枉死城」的说法我只在百度百科等二手转述中见到，**未找到一手依据**。
- **位置**：原文作「環繞本殿之右」，且该章紧接《孟婆神》章（在十殿系统之后），所以是**贴着后段某殿（九殿或十殿，章节界限在转录中不明确）**，而**不是** `docs/10` 说的「酆都城外，靠近莲花台附近」。莲花台本身还是十三站里那个净土宗挪用词。
- `docs/10` §2.3 注「自杀在十八层地狱第十四层（枉死地狱）」——《玉历》一殿讲自尽者的处置是**饿鬼道 / 阿鼻大地狱**，且原文根本没有那份十八层名单。

来源：[维基文库《玉历宝钞·枉死城》](https://zh.wikisource.org/zh-hans/%E7%8E%89%E6%AD%B7%E5%AF%B6%E9%88%94)（**a**）

### 2.5 本会话的改动：剑树狱 / 寒冰狱 / 烊铜狱 退役为「小地狱」——**判断基本正确**

一手核对（《玉历宝钞》）：

- **寒冰**：`寒冰小地狱` 明确是**第二殿活大地狱的第十六小地狱**（原文「十六名寒冰小地狱」）。而且**活大地狱的别名就是「剥衣亭寒冰地狱」**——寒冰是二殿之内的东西，不可能是第十一殿。✅
- **剑树**：《玉历》二殿有 `剑叶小地狱`（「十四名剑叶小地狱」），是**小地狱**；另外「剑树」在《玉历》里作**望乡台城墙的建材**（「以剑树为城」）。佛教宇宙论中「剑树」属八热地狱周边的**十六游增地狱**之一，同样是**附属**层级。✅
- **烊铜**：**《玉历宝钞》原文中不出现「烊铜」一词**。它作为刑罚（灌烊铜）广见于佛经与民间地狱叙事，但**没有任何文本把它立为一个与十殿并列的殿**。所以「不是殿」这个结论成立；但要注意，说它是「《玉历》的小地狱」是**没有依据的**——它在这部文本里压根不在。⚠️

**一处需要标注的分歧**：在**佛教宇宙论**框架里，**八寒地狱**（頞部陀、尼剌部陀…）是与八热地狱并列的**大地狱**，不是附属。所以「寒冰＝小地狱」只在《玉历宝钞》框架内为真。项目既然选定《玉历》为准，判断成立；但 migration 里「They are 小地狱」这句话若不限定框架，是过度概括。

**结论：退役这三行是对的**，理由（不是殿）成立；三行本来也是原 realm 表混乱的产物（realm 表当时用刑罚名和王名混着做主键）。migration 里「不重指历史 disposition」的处理也是对的。建议把 migration 注释改为「在本部署所采的《玉历宝钞》框架下」，并把「烊铜」的依据从「小地狱」改为「无任何文本立其为殿」。
