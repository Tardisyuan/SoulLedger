## 一、冥府的统治者

### 1.1 哈迪斯（Hades / Aïdes；崇拜称号 Plouton）

| 项目 | 内容 | 出处 |
|---|---|---|
| 身世 | 克罗诺斯与瑞亚之子，宙斯、波塞冬之兄 | 赫西俄德 Theog. 453-458【已证】 |
| 怎样得到冥府 | 三兄弟**抽签**分世界：宙斯得天，波塞冬得海，哈迪斯得「幽暗」，大地与奥林波斯共有 | Il. 15.187-193【已证】（说话的是波塞冬） |
| 名字 | 柏拉图说人们怕「哈迪斯」这个名字（被解作「不可见者」），改称「普路同」，因为财富从地下涌出 | 《克拉底鲁篇》403a【已证】 |
| 隐身之盔 | 「哈迪斯的头盔」使戴者不可见；雅典娜曾戴它 | Il. 5.844-845【已证】 |
| 职能 | **统治**冥府，**不审判**亡魂。没有任何一位古代作者让哈迪斯本人做判官 | — |
| 在《高尔吉亚》里 | 普路同与至福岛的监管者一起向宙斯抱怨「两边都来了不该来的人」，这就是审判改制的起因 | Grg. 523b-c【已证，见 GR-GRG-02】 |

> **哈迪斯 / 普路同 / Pluto / Dis Pater 的关系**已在 [`04_希腊冥界详解.md`](04_希腊冥界详解.md) §四写清：
> Plouton 是**希腊**崇拜称号（不是罗马名），Pluto 是它的拉丁转写，罗马本土冥神是 Dis Pater 与 Orcus。
> 本文不重复。另须注意：**但丁的 Pluto（第四圈的看守，Inf. VII）是另一个职位**，本系统也把它当作
> 另一行（见 §五）。

### 1.2 珀耳塞福涅（Persephone；阿提卡称 Kore「少女」）

- **被劫与回归**：《荷马颂歌·致德墨忒尔》（约前 7–6 世纪）——哈迪斯经宙斯默许劫走她；德墨忒尔
  寻女不得、使大地不生；宙斯派赫尔墨斯接回；她因吃了**石榴籽**，每年须有**三分之一**时间留在地下
  （399、445-447、463-465 行【已证】；归来在春天花开时，401-403【已证】）。
  > ⚠️ `04_希腊冥界详解.md` §四原作「冬半年居冥界」（2026-10-24 已改，04 v2.2）。颂歌说的是**一年的三分之一**；「冬天」是
  > 后世的解释，颂歌本身把她的归来与**春天**花开相连。古代对她在地下的季节有不同理解
  > （例如是否对应希腊夏季的干旱休耕期），【存疑】，本文不下定论。
- **在冥府的权柄**：荷马称她「可怖的珀耳塞福涅」；是她让忒瑞西阿斯死后仍保有心智（Od. 10.491-495
  【已证】），是她遣来古代女子的亡魂（Od. 11.225-226【已证】），奥德修斯怕她遣出戈耳工之头而逃离
  （Od. 11.633-635【已证】）。
- **与轮回的关系**：品达残篇 133（经柏拉图《美诺篇》81b-c 引述【已证】）——珀耳塞福涅接受「古老悲痛」
  的偿付之后，在第九年把那些灵魂送回上方的阳光，成为君王、强者与智者。
- **秘仪**：厄琉息斯秘仪的核心神祇之一；颂歌末段说见过秘仪者死后的命运与未入秘者不同（480-482 行
  【已证】；颂歌没有说他们去哪里）。金箔铭片里，死者在她面前自陈身份（见 `01` §2.2 的注）。

## 二、冥府的其他人物

### 2.1 塔纳托斯（Thanatos，死神）与许普诺斯（Hypnos，睡神）

| 项目 | 内容 | 出处 |
|---|---|---|
| 谱系 | 夜神纽克斯之子，二者是兄弟 | Theog. 211-212【已证】；Il. 14.231 称睡神为「死神的兄弟」【已证】 |
| 居所与性格 | 二者住在大地尽头、日光照不到之处；睡神温和，死神铁心铜肝、连众神都憎恶他 | Theog. 758-766【已证】 |
| 最著名的场面 | 宙斯之子萨耳珀冬战死，阿波罗洗净其尸，交给睡神与死神**抬回吕基亚**安葬 | Il. 16.666-683【已证】；这一场面画在欧弗洛尼俄斯的调酒缸上（约前 515）【转述】。收藏地【已证，据意大利文化部公告】：2008 年前在纽约大都会博物馆，归还意大利后 2010 年起在罗马朱利亚别墅国立伊特鲁里亚博物馆常设展出；2015 年 11 月文化部长宣布它与欧弗洛尼俄斯的萨耳珀冬杯（kylix）**留在切尔韦泰里国立考古博物馆**（Museo Nazionale Archeologico Cerite）；文化部 2020 年的页面仍列在该馆 Ruspoli 厅。2020 年以后是否再迁，未查 |
| 舞台上的死神 | 欧里庇得斯《阿尔刻斯提斯》开场死神亲自来取阿尔刻斯提斯，与阿波罗争辩；后来赫拉克勒斯在墓旁与他角力，把她夺回 | Alc. 24-76（开场）【已证】；角力在剧中由赫拉克勒斯转述，1140-1142 行【已证】 |
| 被缚的死神 | 西西弗斯用计锁住死神，人间一时无人死亡 | 【存疑】：见于后世注疏与神话手册，常归于前 5 世纪的斐瑞库德斯；荷马没有这个故事。忒奥格尼斯 702-712【已证】说的是另一个版本：埃俄罗斯之子西西弗斯凭机巧从冥府上来，**用花言巧语说服了珀耳塞福涅**（703-704），从死者的阴影之地、越过关住亡魂的幽暗之门，又回到日光下（707-712）。705 行还说珀耳塞福涅是「给凡人遗忘、损害心智」的那位——一个**不在勒忒河上的遗忘** |
| 维吉尔 | 冥府前庭的众拟人之中有死神、「死神的亲属睡神」 | Aen. 6.273-281【已证】（Letum 与「死神的亲属睡神」，6.277-278） |

> **塔纳托斯取命，不引魂。** 引魂下冥府的是赫尔墨斯（Od. 24.1-14）。两者在后世图像（白底油瓶）里
> 常一起出现，但职能不同。

### 2.2 赫尔墨斯（Hermes，引魂者）

- 职能：引亡魂下冥府（Od. 24.1-14【已证】；该段是否后加，见 `01` §3.1）；也是唯一能自由往返冥府、
  奉命接回珀耳塞福涅的神（《致德墨忒尔颂》334-337【已证】）。
- 称号「Psychopompos（引魂者）」用于赫尔墨斯，文献里最早年代确定的是狄奥多罗斯 1.96.6（前 1 世纪）【已证】，
  LSJ 同列普鲁塔克《道德论集》758b；这个词更早（前 438）用在卡戎身上（Alc. 361【已证】）。《奥德赛》古注说
  阿里斯塔科斯删 24.1 起的冥府段，理由之一正是「荷马的赫尔墨斯不是引魂者」【已证】（详见 `01` §3.1）。
  铭文与崇拜中是否更早，未查【存疑】。「Chthonios（地下的）」的出处本文未核。
  这个词本身在欧里庇得斯《阿尔刻斯提斯》361【已证】已经出现，但用在**卡戎**身上。
- 在阿里斯托芬《蛙》里不出场；在维吉尔卷六里也不是引路者——引埃涅阿斯下冥府的是**西比尔**。

### 2.3 卡戎（Charon）

渡口、渡资、各作者分歧见 [`01_希腊冥府整体架构.md`](01_希腊冥府整体架构.md) §2.3。要点：
**荷马无卡戎**；希腊作者把渡口放在阿刻戎；维吉尔说他只渡已葬者。
`04_希腊冥界详解.md` 已更正「喀戎」错字——喀戎（Chiron）是马人，与冥府无关。

### 3.3 三点容易读错

1. **审判在惩罚之前，是分流点。** 草地不是一层地狱，而是岔路口；希腊冥府没有「第几层」。
2. **审判对象是赤裸的灵魂。** 证人、出身、财富都不再作数（523c-e）；证据就是灵魂本身的「伤疤」（524d-e）。
   这是柏拉图在这里真正要说的：审判不能被修辞与权势影响——也就是对整篇对话中「修辞术」的回答。
3. **「永罚」只给不可医者。** 一般的不义者受罚是为了变好（525b）。《高尔吉亚》没说可医者受完罚之后去哪里；
   这个空缺由《理想国》的千年循环填上，但**两篇不能合并**（见 §四.4）。

### 4.3 数字：千年、十倍、百年

- **一千年 = 十倍 × 一百年**（615a-b【已证】）。《理想国》把「一百年」当作一个人寿的长度，
  所以每件不义罚一次「一生」，罚十次。
- 同一个「千年」也出现在《斐德若篇》（灵魂在两世之间受审、千年后再择生；灵魂要一万年才能重新长出翅膀，
  三度选择哲人生活者三千年即可，248e-249b【已证】）和维吉尔（Aen. 6.748，「转满一千年的轮」【已证】）。
  三处数字相同，**机制不同**，不要互相引作印证。
- 两条路程长度相同：受赏也是千年（614e-615a 写两边都在旅途中，615a 只明说地下的是千年，天上的长度
  **由文意推出**，【存疑】的程度很小，但原文确实只直说了一边）。

### 4.4 《高尔吉亚》与《理想国》不能合并

| | 《高尔吉亚》 | 《理想国》厄尔神话 |
|---|---|---|
| 审判者 | 米诺斯、拉达曼迪斯、艾亚哥斯，具名、分工 | **未具名**的「审判者们」 |
| 地点 | 岔路口草地 | 天地四口之间的「精灵之地」，草地在出口处 |
| 结局 | 至福岛或塔尔塔罗斯，**终局** | 千年后**回来、择生、饮水、再生** |
| 刑期 | 无 | 十倍，百年一期，共千年 |
| 永罚 | 不可医者 | 不可医者（同） |
| 记忆 | 不提 | 饮阿墨勒斯河之水而忘 |

两篇共有的只有「不可医者永罚」与草地这一意象（Shorey 在 614c、614e、615d、615e 的注里交叉引用了
《高尔吉亚》，见 `statutes_republic.py` 文件头）。所以本系统把它们做成**两套语料**，彼此不引用。

### 4.5 《斐多篇》的第三种说法（简述）

《斐多篇》107d-e、113d-114c【已证】：每人的守护精灵把他引到受审之处，再由一位向导带往冥府；
一般的人到阿刻戎湖，净化后受报；犯大罪而可医者（如一时激愤对父亲或母亲动了手、此后终身悔恨者，或以类似情形杀了人者——原文是「动手施暴」，不是「杀了父母」）被抛入塔尔塔罗斯，
一年后随科库托斯或火焰河漂到阿刻戎湖边，须**求得被害者的宽恕**才能上岸，否则再回塔尔塔罗斯；
不可医者永不出来；以哲学净化者从此不再有身体。这是柏拉图第三个、细节又不同的死后神话；
本系统**没有收录**。
