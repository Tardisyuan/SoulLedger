# 城隍体系详解

城隍是中国传统文化中城市的守护神，相当于阴间的"地方官"，掌管一方阴阳两界的事务。

---

## 一、城隍信仰起源

- **起源**：周朝天子祭祀八蜡中的水庸神
- **发展**：汉代开始有城隍祠，唐代普及，宋代以后遍布全国
- **制度化**：明洪武年间朱元璋下旨，城隍祭祀列入国家祀典

---

## 二、城隍层级体系

城隍按行政级别分为四级，与人间地方行政体系对应：

| 级别 | 名称 | 爵位 | 封号（明洪武二年） | 管辖范围 |
|------|------|------|----------|----------|
| 省级 | 都省城隍 | 王（正一品） | 承天鉴国司民升福明灵王 | 管辖省 |
| 府级 | 府城隍 | 公（正二品） | 鉴察司民城隍威灵公 | 管辖府 |
| 州级 | 州城隍 | 侯（三品） | 鉴察司民城隍灵佑侯 | 管辖州 |
| 县级 | 县城隍 | 伯（四品） | 鉴察司民城隍显佑伯 | 管辖县 |

> 封号按明制（《明史·礼志三》）：洪武二年（1369）封京都城隍为承天鉴国司民升福明灵王，府城隍为威灵公、州城隍为灵佑侯、县城隍为显佑伯。
> 明制里封王的是京都城隍（京师一城），没有「都省」一级；本系统把省级（都省城隍）对到这一封号（2026-10-28 用户定）。
> 洪武三年改制去封号，只称「某府（州、县）城隍之神」；系统取洪武二年的封号作显示用，界面上与级别并列（`cityGods.rank_titles.*`）。

> 城隍爷级别越高，下属二十四司配置越齐全。

## 三、二十四司（城隍的下属机构）

城隍神务繁重，仿古时六部（吏、户、礼、兵、刑、工），每部各设四司，共二十四司：

### 3.1 阴阳司（总务）

| 司名 | 职能 |
|------|------|
| 阴阳司 | 辅佐城隍爷督察阴阳两界的总管 | 掌理阳世之善恶，记录功过 |
| 说明 | 二十四司之首，相当于秘书长 |

### 3.2 吏部（人事）

| 司名 | 职能 |
|------|------|
| 功曹司 | 考核记录亡魂生前功过 |
| 典籍司 | 掌管亡魂名册簿典 |
| 记簿司 | 登录亡魂生前言行 |
| 都官司 | 调度鬼卒执行任务 |

### 3.3 户部（民政）

| 司名 | 职能 |
|------|------|
| 财帛司 | 管理阳间纸钱、元宝接收 |
| 土地司 | 管辖境内土地事务 |
| 粮秣司 | 管理粮食储存分配 |
| 考劫司 | 记录人在阳间寿夭劫数 |

### 3.4 礼部（礼仪）

| 司名 | 职能 |
|------|------|
| 祭祀司 | 掌管祠庙祭祀事务 |
| 仪注司 | 制定祭祀礼仪规范 |
| 祸福司 | 宣告祸福吉凶 |
| 冥衣司 | 管理亡魂衣物冥器 |

### 3.5 兵部（军事）

| 司名 | 职能 |
|------|------|
| 兵杖司 | 掌管刑罚器具 |
| 刑讯司 | 审讯罪犯亡魂 |
| 拘捕司 | 缉拿游魂散鬼 |
| 巡察司 | 巡查阳间善恶 |

### 3.6 刑部（司法）

| 司名 | 职能 |
|------|------|
|| 刑罚司 | 执行各种刑罚 |
|| 案簿司 | 整理案件卷宗 |

### 3.7 工部（工程）

| 司名 | 职能 |
|------|------|

| 输运司 | 押送亡魂来往各站 |

## 四、城隍的主要职能

### 4.1 阴间地方官职能

| 职能 | 说明 |
|------|------|
| 护城安民 | 保护城市安全，防御灾祸 |
| 管辖亡魂 | 接收、管理本地区亡魂 |
| 监察善恶 | 记录境内居民善恶行为 |
| 缉拿鬼魂 | 派遣黑白无常等勾魂 |
| 上报下达 | 向地府上报，传达审判结果 |

### 4.2 文武判官（城隍的左右手）

| 判官 | 职能 |
|------|------|
| 文判官 | 掌管文书、记录、审核 |
| 武判官 | 协助缉拿、押送、刑罚执行 |

## 五、城隍与上级的关系

```
后土皇地祇
    │
    ├──→ 酆都大帝 ──→ 五方鬼帝 ──→ 十殿阎罗 ──→ 四大判官
    │
    └──→ 东岳大帝
              │
              └──→ 城隍（地方官）
                        │
                        ├──→ 土地公（乡镇级）
                        │
                        └──→ 二十四司
```

**管辖关系**：
- 城隍受东岳大帝和酆都大帝双重管辖
- 城隍可直接向十殿阎罗报送案件
- 城隍的审判结果可上诉至十殿阎罗

> **系统里的做法（代码现状）**：城隍**不下判决**，只做初审——解送十殿（SENT_ON）、退回补正（RETURNED）、
> 由管理员改交另一位城隍；案子在城隍处时十殿不能认领、结案（409 `at_city_god`）。所以系统里没有
> 「对城隍判决的上诉」，申诉针对的是十殿结案后的审判（`backend/apps/judgment/appeals.py`）。
> 见 `backend/apps/judgment/city_gods.py` 文件头。

## 六、城隍的诞辰与祭祀

| 项目 | 内容 |
|------|------|
| 诞辰 | 各城隍不同，如福州城隍五月初五 |
| 祭祀日 | 明洪武后规定每年清明、七月十五、十月初一祭祀 |
| 庙会 | 城隍出巡（抬城隍像游街） |

---

## 七、城隍与土地公的区别

| 对比项 | 城隍 | 土地公 |
|--------|------|--------|
| 级别 | 较高（县级/市级/省级） | 最低（乡镇级） |
| 管辖范围 | 整个城市 | 一方土地 |
| 职能 | 阴间地方官，审判职能 | 管理一方土地和亡灵 |
| 祭祀规格 | 较高，国家祀典 | 较低，民间小祭 |

## 九、城隍系统与管理系统映射

| 城隍元素 | 管理系统概念 |
|----------|--------------|
| 城隍爷 | 地方分公司总经理 |
| 文判官 | 行政总监 |
| 武判官 | 运营总监 |
| 二十四司 | 各职能部门 |
| 土地公 | 基层管理员 |
| 黑白无常 | 外勤执行人员 |

> **已实现的部分（2026-10-28，只在地府）**：
> - 四级：`CityGod.rank`（`PROVINCE` 都省 / `PREFECTURE` 府 / `DEPARTMENT` 州 / `COUNTY` 县，`CityGodRank`）；
>   诸司：`CityGod.bureaus`（阴阳司加六部各四司，`CityGodBureau`），见 `backend/apps/judgment/models.py`，
>   接口 `/api/v1/judgment/city-gods/`。
> - 土地公：`TudiGod`（`backend/apps/death_sync/models.py`），上级只能是本殿的县城隍（未定级的照收），
>   以他的名义登记死亡（`/death-sync/tudi-gods/{id}/register-death/`），案子交上级城隍初审
>   （`backend/apps/death_sync/tudi_views.py`）。
> - 勾魂：城隍发勾魂牒（`CaptureWarrant`，派黑白无常或牛头马面），拘到、交接时登记死亡
>   （`backend/apps/dispatch/capture.py`，接口 `/api/v1/dispatch/capture-warrants/`）。
>   死亡经别的路登记（死亡同步、土地公、手动）时，牒随之签发并记为已交接（`capture.py::close_on_death`，2026-10-30）。
> - 文武判官不单独建模；城隍名下的官员即办事人（`CityGod.officers`）。
