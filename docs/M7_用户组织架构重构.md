# M7 - 用户与组织架构重构

## 背景

将 Actors（演员/角色）合并到 User 表，各文明从"地域"改为"组织架构"，实现类似 Snowy 的多租户 RBAC 模型。

## 新架构设计

### 核心模型变更

| 当前模型 | 新模型 | 说明 |
|---------|-------|------|
| `actors.Actor` | 合并到 `auth.User` | Actor 表数据迁移到 User 表 |
| `civilization` (CN/EU/EG) | `Organization` 表 | 组织架构树形结构 |
| `perm.Role` | 保留，分 GLOBAL/ORG 作用域 | 权限角色 |

### 数据模型

#### 1. Organization 组织架构表

```python
class Organization(AuditUserFields):
    """组织架构 - 替代原来的 civilization"""
    name = CharField(max_length=100)           # 组织名称：十殿/天堂地狱/杜阿特
    code = CharField(max_length=20, unique)   # 编码：DIYU_CN / HEAVEN_EU / DUAT_EG
    parent = ForeignKey('self', SET_NULL)     # 父组织（平行部门）
    category = CharField(max_length=20)        # 分类：CHINESE/EUROPEAN/EGYPTIAN
    sort = IntegerField(default=0)            # 排序
```

#### 2. User 模型扩展

```python
# 继承 auth.User，新增字段
class User(AbstractUser):
    """统一用户表 - 合并 Actor"""
    display_name = CharField(max_length=100)      # 显示名称：阎罗王/哈迪斯
    phone = CharField(max_length=20, blank)       # 电话
    avatar = URLField(blank)                     # 头像
    organization = ForeignKey(Organization)       # 所属组织
    position = CharField(max_length=100)         # 职位：第一殿殿主/冥王
    is_active = BooleanField(default=True)

    # Actor 迁移字段
    ext = JSONField(default=dict)                # 扩展信息（原 Actor.ext）
```

#### 3. Role 权限角色（保留，扩展作用域）

```python
class Role(AuditUserFields):
    """权限角色 - 新增 category 字段区分作用域"""
    name = CharField(max_length=20, unique)      # ADMIN/JUDGE/GUARDIAN/VIEWER
    display_name = CharField(max_length=100)
    parent = ForeignKey('self', SET_NULL, null)  # 角色继承
    scope = CharField(max_length=20)              # GLOBAL/ORG（新增）
    organization = ForeignKey(Organization, null)   # ORG 角色专属组织
```

**角色作用域：**
- `GLOBAL`：系统级权限（ADMIN、超级管理员）
- `ORG`：组织级权限（JUDGE只能操作本组织内的灵魂）
