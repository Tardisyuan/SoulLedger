# SoulLedger · 规范 v3 · 给 Design 的第八批：官员两步验证(2026-10-09)

官员台要加两步验证(TOTP 动态码)。后端会先做，请设计界面。范围只限官员;灵魂端 App 不需要。请沿用 A9 登录页的骨架和 v3 组件，出 1440 浅色、1440 深色、393 三档。

## 一、要设计的界面

1. **登录第二步**(接在 A9 登录页之后)
   - 输入账号密码后，开了两步验证的账号进入第二步，输入 6 位动态码。
   - 「在此设备上 30 天内不再询问」勾选项。
   - 「改用恢复码」入口：输入一次性恢复码。
   - 状态：输入中、码错误(剩余次数)、尝试过多被锁定(多久后可重试)、码已过期、网络错误。
   - 返回第一步的入口。
2. **开启两步验证**(个人中心里)
   - 步骤：说明 → 扫码(二维码，以及可手动输入的密钥)→ 输入一次动态码确认 → 显示恢复码(10 个)→ 完成。
   - 恢复码只显示这一次，要有「复制」「下载」,以及一句「我已妥善保存」的确认，才能完成。
   - 中途退出不生效。
3. **个人中心里的状态与管理**
   - 已开启：开启时间、最近一次使用;「重新生成恢复码」;「关闭两步验证」(需要再输一次动态码或密码)。
   - 未开启：一句说明和「开启」按钮。
4. **管理员侧**(用户管理页)
   - 用户列表能看出谁开了两步验证。
   - 「重置两步验证」:用户丢了手机时，由管理员清除;要二次确认，并写审计。
   - 管理员能否强制某个角色必须开启，请给出一个开关的位置(例如权限设置或殿设置)。

## 二、必须遵守
- 状态用字形加文字表示，不能只靠颜色。
- 控件高度 44 / 48 / 56;圆角：控件 4,面板 8。
- 动态码输入框：请给出是 6 个分格还是 1 个框，以及粘贴、自动填充(iOS / Android 短信码)、读屏软件下的行为。
- 文明色只用在 v3 规定的五处。
- 新增文案请列中文和英文，egy 我们按词表处理。
