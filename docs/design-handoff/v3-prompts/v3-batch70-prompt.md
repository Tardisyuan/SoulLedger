# SoulLedger · Design v3 · 第七十批 · 作品演示版的门面(2026-11-02)

用户看了线上演示(https://soulledger.tardisyuan.ltd/),原话:「好像没有啥特色啊,点进去」。这批要解决这个。

## 背景
- 这是**只给作品展示用**的 Web 演示:没有后端,数据是录好的,每次登录回原样。访客是招聘方和同行,一般只看一两分钟。
- 这些设计**只进演示版**,正式版的落地页、登录页不变。
- **演示版默认语言是英文**(用户 11-02 定),中文与 Kemet 可切换。画布请以英文为主版,并看一眼中文下也成立。
- 现状的问题:落地页黑白,四个文明只是四行字且点不进去;入口写「控制台」;登录页是判官 / 管理员 / 版主三个按钮,判官固定在中国第五殿,埃及称心、九层地狱这些最有特色的东西碰不到;管理员是纯黑主题;进去之后不知道看什么;技术实力一字不提。

## 请设计(桌面 1280 与窄屏 393 各一版,亮暗两种主题)

### 1. 落地页 `/`
- **首屏**:一句话讲清这是什么,让人想点。不要写成产品宣传语,可以继续用典籍句子的气质。修掉现在贴左边缘的问题。
- **四张文明大卡片**,是页面的主角:中国地府、欧洲天堂与地狱、埃及冥界、希腊冥界。各用自己的 ink 配色、纹样、徽记(沿用灵魂端 App 的匾与纹样,如埃及的拱门与羽毛、中国的「冥」字印)。每张写一句它最有特色的审判,点击即以这个文明的判官身份进入:
  - 中国:十殿、六道轮回、孟婆汤
  - 欧洲:圣彼得与炼狱、但丁九层地狱
  - 埃及:奥西里斯审判、心脏称重、否定告白
  - 希腊:三判官分流、尼尔的千年循环、勒忒之水
- **次要入口**:管理员(看权限、用户、审计)、版主(朋友圈审核),小一些。
- **「这是怎么做的」**一节:给懂行的人。放架构示意(Django + Channels / Next.js / 两个 Expo App / packages/core 四端共用 / 多租户隔离 / Matrix 书信)、真实数字、两个 App 的录屏位、GitHub 链接。真实数字(2026-11-02 实测,请作为可替换的数据位,不要写死样式):后端测试 7760 条、Web 5635 条、灵魂端 1201 条、官员端 1095 条、E2E 三引擎各约 270 条。

### 2. 「一个灵魂的一生」导览
进入后的一张小卡片,带访客走:死亡 → 勾魂 → 审判 → 处置 → 受刑 → 转生,约六步、三分钟。每步一句话说这一步在系统里发生什么,点「下一步」跳到对应页面并高亮要看的东西。
- 不能挡住页面内容;可收起成一个小角标;窄屏也能用。
- 要有进度(第 n / 6 步)、跳过、走完后的收尾(回到四张卡片,换一个文明再看)。
- 每个文明的步骤名按它自己的词(埃及是「称心」,不是「审判」;埃及、欧洲没有转生,终点不同,步数可以不同)。

### 3. 进入时的过渡
点文明卡片到进入后台的那一下,给一点仪式感(例如落印),短、可跳过,尊重 `prefers-reduced-motion`。
