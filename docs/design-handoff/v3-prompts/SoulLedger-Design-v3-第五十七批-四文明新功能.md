## 一、中国 · 审判台

### 1. 罪目(决定送哪一殿)
- 位置:审判台 `app/judgment/[id]` 资料舱「供词」栏顶部。组件 `src/components/judgment/DiyuCaseFields.tsx` → `OffenceField`。
- 背景:以前按严重度分殿,现在按罪目分殿(23 个罪目,对应二至九殿,五逆归九殿)。没填罪目时仍按严重度。
- 状态:可编辑 / 只读 / 未填(小字「按严重度选殿」)/ 已填(小字「判有罪时自动送第 N 殿」)/ 已结案(不显示提示)。
- 临时做法:原生 `<select>`,按殿分组(optgroup)。
- 请定:放在「供词」还是「戊 · 发落」旁边;要不要显示殿名、狱名;窄屏怎么排。

### 2. 枉死城块
- 位置:同一文件 `WangsiPanel`,只在枉死的案子上出现。
- 内容:死因(5 类)、冤情等级(无 / 轻 / 重 / 极重)两个下拉;申诉流程。
- 状态:无申诉(申诉输入框 +「提出申诉」)/ 已申诉待审(审核意见 +「属实 · 提前释放」/「不属实」;等级不到「重」时「属实」置灰)/ 属实已释放 / 不属实(可再提)/ 只读 / 报错文字。
- 临时做法:左侧竖线分块,两列网格,没有确认弹层。
- 请定:「提前释放」不可逆,要不要二次确认;和页头「枉死 · 候至 日期 · 在枉死城」那一行怎么呼应。

### 3. 城隍:级别与诸司
- 城隍编辑抽屉 `CityGodEditor`:「级别」(都省 / 府 / 州 / 县城隍,带封号,如「府城隍 · 绥靖侯」)和「下属诸司」(25 个司,按阴阳司 + 六部分 7 组)。临时是原生下拉 + 7 行复选框,太长。请定:折叠、还是按级别给预设。
- 城隍列表 `app/city-gods`:新增「级别」「下属诸司」两列;诸司现在只显示「N 司」,全名在悬浮提示里。
- 初审队列 `app/city-god-cases`:城隍名后面的级别小字。
