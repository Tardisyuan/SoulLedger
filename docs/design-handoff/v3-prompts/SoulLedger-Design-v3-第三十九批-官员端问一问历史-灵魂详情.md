# 第三十九批 · 官员 App:「问一问」历史与建议问题、灵魂详情(2026-10-17)

P3 里最后两条，都在官员 App 上。后端接口基本都有，缺的是手机上的界面。
产品方向不变：官员 App 做日常查看与操作，宣判、盖印、流程编辑只在电脑上做，所以这两件都是**只读或轻操作**。

---

## 一、「问一问」:历史对话与建议问题(O-13)

**现状**
- 入口在「查询」页签顶部的分段控件「查灵魂 / 问一问」。
- 屏上是一问一答往下排，下面一个输入框和发送键。
- 同一次打开里能接着问。但**切到别的页签就全没了**,也看不到以前问过什么。
- 空着的时候没有任何提示该问什么。

**后端已有**
- 本人的全部历史对话：每条有来自哪一页、开始时间、最近一次时间、第一句问题、全部问答。
- 可以删除单条对话。
- 对话保留 30 天，之后自动清掉。
- 点开一条旧对话可以接着问。

**另两端已有的样子(供参考，不必照搬)**
- 网页右侧抽屉，头部有「历史」「新对话」。
  - 空对话时显示一句引导和 2 条建议问题，点一条直接发出。
  - 历史列表每行：页名 · 时间、第一句问题(单行截断)、删除。
  - 列表顶上一行写明保留 30 天。
- 灵魂 App 是底部弹层，在「对话 / 历史」之间切换。
  - 空对话时显示 3 条带边框的建议问题。
  - 历史每行：页面标签 + 时间(今天写「今天 HH:mm」)、第一句问题两行、× 删除，删除前在弹层里确认。

**我们这边定的(不用你定)**
- 建议问题沿用网页那张「角色 × 页面」的表，每格 2 条，内容不改。
- App 每个页签对应一个页面：待办、审判、查询、通知、我的。问一问知道你是从哪一页来的，建议问题跟着变。

**要的稿**
1. 入口：继续放在「查询」页签的分段控件里，还是改成每个页签都能叫出来的按钮或底部弹层?
   - 改成后者，「从哪一页来」才有意义，建议问题也才能跟着页面变。
2. 空对话：引导句与建议问题的样子(几条、竖排还是横排、点了直接发出还是先填进输入框)。
3. 历史列表：放在哪(同一屏切换?单独一页?),每行写什么，删除怎么确认。
   - 列表要不要按「今天 / 更早」分组?
   - 30 天保留的说明放在哪?
4. 「新对话」的入口。
5. 从历史点开一条旧对话时的样子：是否标出「这是 10-15 的对话」,能否接着问。
6. 空历史、载入失败、删除失败的写法。

## 二、灵魂详情更丰富(O-15)

**现状**
- 只显示 4 项：姓名、状态、文明、生卒；暂居时多一行「暂居 · 原属」。
- 下面一句「只读」,最后是「在电脑上继续」。
- 进入方式：「查询 › 查灵魂」的搜索结果、和灵魂有关的通知。
- 待办详情和审判详情里出现的灵魂名字**点不进去**。

**网页灵魂详情有、手机可以考虑放的(都只读)**

| 区块 | 内容 | 谁能看(按权限，不按角色) |
|---|---|---|
| 页头数字 | 功 / 过 / 余额、第几世 | 都能看 |
| 身份 | 文明、出生、死亡、地点、原名、生平描述 | 都能看 |
| 审判 | 每一世的审判：案号、判决、状态，点进审判详情(App 已有) | 有审判读权限的人(管理员、版主、审判官) |
| 功过记录 | 逐条：日期、功或过、分值、来源、描述 | 都能看 |
| 处置与轮回 | 去处、性质、是否执行、是否永久;轮回形态与时间 | 处置：守卫以上;轮回：都能看 |
| 受刑计划 | 计划各站与当前到了哪一站 | 有审判读权限的人 |
| 生命周期事件 | 和网页「灵魂事件」一样的条目(第三十七批的事件名) | 都能看 |

**手机上不放的(只在电脑上)**:编辑、删除、归档、标记死亡、开始审判、轮回、更正结案、重算功过、发起审批、撤销受刑计划、修日期问题。

**要的稿**
1. 一屏的结构：所有区块从上往下排，还是页头之下分页签(例如 概况 · 审判 · 功过 · 去向 · 事件)?
2. 页头：字号头像、名字、状态、编号、功 / 过 / 余额怎么摆在手机宽度里。
3. 每个区块在手机上的行样式。功过记录、事件可能很多：一页先显示几条，「加载更多」怎么放?
4. 没有权限的区块：直接不出现，还是出现一行「需要 ×× 权限」?(网页是不出现，案号写 —。)
5. 待办详情、审判详情里的灵魂名字改成可点(点了进这个灵魂详情):要不要一个视觉记号，表示这是链接?
6. 暂居在外的灵魂、已归档的灵魂，页头怎么标(App 已有「暂居 · 原属」这句)。
7. 空状态(还没有审判、还没有功过记录)与载入失败。
