# 第四十五批 · 灵魂「出身地域」与希腊冥界按来源分流(2026-10-19)

第四十四批的埃及文已全部上线。这一批是一个小的新字段，加上流程图里的一处新画法。zh-Hans / en / egy 三语照旧，egy 只用词表里已有的词。

## 背景

- 希腊冥界的常规审判按柏拉图《高尔吉亚》524a 做：亚洲来的亡魂由 Rhadamanthus 审，欧洲来的由 Aeacus 审，两人只审其中一人；两人存疑时才交 Minos 终裁。
- 现在流程是一条直线：Aeacus → Rhadamanthus → Minos，每个灵魂三人都要过，不对。
- 产品 10-19 定：
  - 灵魂新增一个字段「出身地域」，三个取值：欧洲 / 亚洲 / 不详。
  - 流程第一步按这个字段自动分流：欧洲 → Aeacus，亚洲 → Rhadamanthus，不详 → 直接交 Minos。
  - Aeacus 或 Rhadamanthus 通过，流程即结束；驳回(存疑)才交 Minos。
  - Minos 通过即结束，驳回即不通过。
- 这个字段对所有文明的灵魂都有，但目前只有希腊流程用它。

## 要的稿

1. **网页：登记灵魂 / 编辑灵魂的表单**里加「出身地域」：三选一，默认「不详」。
   - 放在「籍贯」旁边。籍贯是自由文本(如「钱塘」)，出身地域是归类，两者并存。
   - 希腊殿的灵魂要不要提示「影响审判由谁主审」？请给一句说明文案，或者说明不需要。
2. **灵魂详情**(网页详情页的信息卡、预览抽屉、官员 App 灵魂详情)：在「籍贯」旁边显示出身地域；值为「不详」时怎么显示。
3. **流程编辑器与流程详情里的「自动分流」一步**：它是自动走的一步，没有审批人，按出身地域分三条出口。
   - 编辑器画布上这一格、三条出口线的标签各怎么写；
   - 流程详情里这一步走过后怎么记，例如「按出身地域分流 → 欧洲 → Aeacus」；
   - 选站时这一步不出现在勾选列表里。Aeacus 和 Rhadamanthus 都是分流的去处，选站时锁住，不能跳过。理由行是否沿用第四十四批 `workflow.pick.jump_target_reason` 的写法，还是另写一句。
4. **编辑器条件分支里的「事实」下拉**：新增一项「出身地域」，值为欧洲 / 亚洲 / 不详。只要三语标签。
