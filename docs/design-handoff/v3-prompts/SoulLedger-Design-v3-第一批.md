## 共同约束（v3 已定，代码里已落地）

**颜色**
- 中性色：canvas #EFEFEB / #10120F，surface #FBFBF8 / #1A1D19，ink #181A17 / #F0F1EA，muted #646861 / #A7ACA4，line #D1D3CD / #383C35。
- 文明色（浅 / 深）：
  - 地府 #8F3329 / #AD4B40
  - 欧洲 #583875 / #80609A
  - 埃及 #294A8A / #5F7FBE
  - 希腊 #285051 / #5A8480
- 文明色只出现在五处：匾（身份带）、导航当前项、印、主按钮、行首「待我处理」色标。组件整体是中性的。
- 状态色只有三种：
  - 冷玫红 #B42350 / #FF7A9A：只用于失败、出错。
  - 危险实底 #8F2430 / #C84C5A：只用于不可撤回的删除按钮。
  - 橙 #A65000 / #E07A23：只用于可撤回的危险操作。
- 判决与灵魂状态一律用「字形 + 文字」表示，不用颜色：
  - 判决：✓ 通过、✕ 不过、◇ 待定、↺ 重审
  - 灵魂状态：○ 在世、◇ 审判中、▣ 已处置、↻ 轮回中、≡ 已终结、◌ 迷失
- 图表不用彩色分类：
  - 灵魂状态用冷灰蓝明度梯度。
  - 去向按界分图案：炼狱实底、天界半色、地狱斜线、中立空框。

**形状与层次**
- 圆角：输入框和筛选标签 4px，弹窗 8px，其余一律方角。按钮保持方角（用户拍板）。
- 阴影只有两档：
  - raised：资料舱、批量条
  - overlay：弹窗、抽屉

**字号**
- 字阶共八档：11 / 12 / 13 / 15 / 20 / 28 / 40 / 56。
- 标题层级：
  - 页面标题 20 / 600
  - 面板标题 20 / 600
  - 列表行标题 13 / 500
  - 区块标签：11 号，大写，界面字体（不用等宽）
  - 正文 13
  - 首页封面标题 28
- 衬线体只用于「有人说的话」：律条、供词、判词。

**控件尺寸暂不改**
- 按钮 28 / 32 / 40，表格行约 40px。v3 的 44 / 48 / 56 和 64px 行高已记录在案，先不采用。
- 稿子请按现尺寸画；如果某页在现尺寸下明显太挤，在旁边标出来。

**表格行**
- 悬停：4% 墨色底。
- 选中：7% 墨色底，**不画行首竖条**。行首 3px 竖条只表示「待我处理」。

**批量条**
- 墨色反白实底。
- 条上的警示用条本身的字色加 ◐，不用橙色（橙色字在墨色底上对比度不够）。

**其他**
- 动效：80 / 160 / 240 / 320ms。曲线：进场 (.2,.8,.2,1)、出场 (.4,0,1,1)、强调 (.2,.8,.3,1)。减少动态效果时全部归 0。

## A. 第一批三类专用页面

这几类是组件库拼不出来的：它们各自的信息结构特殊，直接套表格会很难用。

每页请出 1440 浅色、1440 深色、393 浅色三张。审批流编辑器 393 下是只读，画只读态即可。

### A1. 审批流编辑器（`/workflow`、`/workflow/[id]`）

**现在有的：**
- 列表页三个标签：已有模板 / 编辑器 / 实例。
- 编辑器布局：
  - 工具栏：模板名、文明、案件类型（9 种）、优先级 0/1/2、版本徽章（已发布 vN / 未发布）。
  - 按钮：加节点、自动布局、删除所选、「! 校验 · N」、存草稿、发布。
  - 左侧是节点调色板，中间是 xyflow 画布（点阵、缩放控件），右侧是检查器，底下是线性预览条。
  - 1024 以下编辑器只读。
- 节点：
  - 四种：审批 □、会签 ⧉、通知 ✉、结束 ■。
  - 派生角色：入口 ▷、步骤 □、分支 ◇、终点 ■。
  - 字段：名称、类型、殿号、审批人类型/角色、会签人与门槛、驳回到、超时小时数与超时动作。
- 连线：通过 / 不通过两个出口，加条件分支。条件由 余额(< ≤ > ≥ =)、文明 ∈、判决 ∈ 组成。连线标签形如「是 · 余额 < 0」「否 · 默认」。
- 检查器：节点字段、校验问题列表（16 种问题码）、审批人预览、出口条件编辑、版本历史。
- 实例详情：节点列表高亮当前节点、当前节点卡、判决单选、备注、提交 / 推进 / 升级三个按钮、信息卡、节点与历史两个标签。

**请画：** 编辑器整页，包括选中节点、条件分支、校验有问题三种状态；实例详情；节点与连线的 v3 画法，以及文明色能不能、该不该进画布。

### A2. 界域拓扑（`/realms`）

**现在有的：**
- 文明切换：四个按钮。
- 左侧是路线图（列表加连线，不是图形引擎），形状随文明变：
  - 地府：一条直线。
  - 欧洲：漏斗，地狱 / 炼狱 / 天堂三段，按层排。
  - 埃及：主干，然后分成过 / 不过两条路，不过那条以虚线方框收尾。
  - 希腊：主干，然后分成左右两条路。
- 每个站：名称、有灵魂时实心标记、在押人数。路线图本身不可点。
- 右侧是树表：名称、代码、类型徽章、在押 / 容量（满了要标出）、永恒。
- 有 `realms.manage` 权限时，容量可就地编辑，并提示「将满」。

**请画：** 四种文明各一张路线图；树表与就地编辑；四种文明在同一页里如何既保持各自的空间语法，又共用组件。

### A3. 律条语料阅读器（`/corpus`）

**现在有的：**
- 七部语料，依次为功过格、地狱律、神曲·地狱篇、七宗罪、四十二否认、高尔吉亚、理想国·厄尔。

  - 篇名、原文（只有功过格有）、译文、注、出处、上一条 / 下一条。
- 右栏：引文字符串加复制、插入审判台、被引用次数、相关条目、版本（目前是缺口）。

**请画：** 三栏阅读器，正文用衬线体；四种编号体系的标题样式；搜索命中态；393 下的阅读体验。

## B. 待审项（不用画）

### B1. 中性色的四档推导值

v3 只定义了五个中性角色，代码里另有四档是推导出来的，需要你们确认或给定值：
- **surface-2**：浅 #E9EAE5 / 深 #272A25。为了让 muted 和 warning 在它上面达到 4.5:1，浅色版提亮过。
- **surface-3 / rule**：暂时等于 v3 的 line。
- **line-strong**：浅 #5B5F59 / 深 #959A93。用于输入框边框，对 surface 要 ≥ 3:1。
- **block**：暂时等于 ink。

### B2. 深色下埃及、希腊匾上的白字

v3 自己的令牌页已注明这两格「仅 ≥15px 粗体」：白字对比度分别只有 3.99:1 和 4.16:1。

代码已经加了守卫：匾题字最小一档 20px / 600，满足 WCAG 大号文字的 3:1。请确认是接受这个限制，还是调整这两个深色值，让白字到 4.5:1。
