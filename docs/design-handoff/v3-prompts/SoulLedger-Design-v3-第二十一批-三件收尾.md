## 三、交付单的两处出入,请定

**1. 已线下交付、但初始密码已过 72 小时的行,能不能补打?**

你的回复里有两句在这种行上冲突:
- 「已线下交付:只剩『补打交付单』。单上没印密码,补打没有风险。」
- 「已过期、已作废:不给打印,因为单上的有效期已经不对了。」

现在的做法是**不给补打**(按第二句)。如果你认为已交付的行任何时候都该能补打存根,请说明这时单上「有效至」那一行怎么印(照印原来的时间 / 印「已过期」/ 不印)。

**2. 审计日志里「打印交付单」怎么显示。**

你定的动作名是 `credentials.print_slip`。审计表的「动作」是一个固定的短枚举(查看 / 创建 / 修改 / 删除 / 执行 / 导出…),放不下这个名字,所以现在记成「执行」,`credentials.print_slip` 写在明细里。结果是:审计页按动作筛选时,筛「执行」能看到它,但没有单独的「打印交付单」一项。

两种做法请选一个:
- (a) 保持现状,在明细里能看到是打印交付单就够了;
- (b) 给审计的动作枚举加一项「打印」(以后别的打印也归这一项),并给出它的 zh / en / egy。
