稿:`DeliverySlipBoard.dc.html`
- A · 骨架与禁区
- B1–B4 · 四种文明的黑白稿(B4 用英文排)

单张组件是 `DeliverySlipCiv.dc.html`,参数有 `civ` / `color` / `lang`。第一稿留在 `DeliverySlipCivV1.dc.html`。

## 一、思路

第一稿的问题是只换了线,四张看起来几乎一样。第二稿让每个文明多了一条**匾额带**:上联顶部是一条整宽、60 高的实心带,殿名用白色反白印在上面。它对应 App 里的身份带,所以灵魂拿到纸,看到的是和屏幕上同一个"门脸"。

- 实心黑块是激光机最拿手的:不会网点化,复印也不会糊,比任何淡底纹都显得郑重。
- 每个文明的特色集中放在三处:匾额带的**底边纹样**、带子**正中的纹章**、**外框**。四张的骨架完全一样。

| 文明 | 匾额带 | 外框 | 殿印 |
|---|---|---|---|
| 酆都 CN_DIYU | 黑匾,里面一圈白线(匾额的双边),两端各有上下一对白色回纹 | 方角双线(2 + 0.75),底部两个内角各一个回纹 | 方印 |
| 杜阿特 EG_DUAT | 黑楣,正中一个白色**有翼日轮**,底边一行白色楣饰(拱形小柱) | 单线,两侧加 0.5 的柱线;底部 3 粗地线 + 0.5 细线 | 圆顶椭圆印 |
| 天堂 / 地狱 EU_HEAVEN_HELL | 底边是一排**尖拱**(36 个),正中一个白色**四叶玫瑰窗** | 内凹角双线,上下边正中各一个菱形 | 圆印 |
| 哈迪斯 GR_HADES | 顶边一行白色**齿饰**,底边一行白色**回字纹** | 单线 1.5,内侧加 0.5 细线框 | 六角印 |

其余:
- 正文区底部的文明分隔线保留(双线 / 点线 / 菱形 / 回纹)。
- 存根加了一个 0.5 的细框,标题下面用同一条文明分隔线。

## 二、6 件事

### 1. 黑白为准,彩色是点缀

- 彩色时,**匾额带、框、分隔线、殿印**换成文明色(C1)。正文、二维码、密码框、签收线仍是纯黑。
- 匾额上的白字落在文明色上,对比度在 4.5 以上(和 App 身份带同一组色值)。
- 官员台「打印交付单」旁边加一个勾选项「彩色点缀」,**默认关**,记在这台电脑上。浏览器判断不了打印机是不是彩色的。
- 所有文字都是 100% 黑或反白,不用灰字。

### 2. 装饰的 SVG

- 匾额上的白色纹样固定用 `#fff`。

- **四种都不用底纹。** 文明特色已经由实心匾额带承担,淡底纹在激光机上只会显得脏。

### 3. 殿印

- 用 `Seal` 组件,**size 64**(身份带档),挂在匾额带正下方、左栏右端,和 App 身份带里印的位置关系一致。
- 黑白时印转成纯黑。
- `seal_glyphs` 为空时,Seal 会自动退回文明默认印字(冥 / J / 𓆄 / Μ)。只有不属于任何文明的殿,这个位置才放 `BrandMark`。
- 品牌标移到页脚,14 高。

### 4. 「更高级」靠什么

- **一大块实心**:匾额带是整张纸的重心。其他地方都很轻,所以显得郑重,而不是热闹。
- **反白标题**:殿名和单据名用 `--font-title` 24。单据名中文字距 0.3em,英文 0.06em。眉题(文明名、灵魂簿)用 11px、0.24em 字距。
- **线有三档**:框 1.5–3;分隔线 0.75–2;行线和竖线 0.5。
- **编号**:34px 等宽 600,3-4-3 分组,组间距 20,仍是纸上最大的字。
- **留白**:二维码独占右栏,静区是纯白。正文左边有 96 宽的标签栏。

### 5. 字体

| 用在 | 字体 |
|---|---|
| 殿名、单据名(只有这两处) | `--font-title` |
| 编号、时间 | `--font-mono` |
| 其余所有文字 | `--font-sans` |
| 殿印 | Seal 组件自带 |

不用 `--font-serif`。

### 6. 语言

- 装饰里没有任何文字,三种语言共用。
- 文明名取 `plaque.realm.<civ>`,殿名取当前语言的殿名。
- 埃及文界面排法同英文(B4)。

## 三、尺寸与禁区(A)

- **上联改为 210 × 105 mm(794 × 397)**,原来是 99。多出的 6 mm 给匾额带。DL 信封内径 110 × 220,不用折也能放进去。剪线相应下移到 397。
- **二维码**:160(42.3 mm),在 (565, 118)。静区四周外扩 26,区内没有墨:匾额带底边在 92,竖线在 536。
- **编号**:四周外扩 8,不能有装饰。
- 四种文明的匾额带一律 32–92,文字区 38–82。所有纹样只出现在带的顶边或底边,不进文字区。
