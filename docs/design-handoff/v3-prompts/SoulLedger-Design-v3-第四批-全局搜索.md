## 后端现状(代码已有，不用新接口)

下面三类数据都能按关键字搜，每类可以只取前 5 条：

| 类 | 能搜的字段 | 备注 |
|---|---|---|
| 灵魂 | 姓名、编号 | |
| 案件 | 案号、编号 | 案号是**精确匹配**,例如 `CN-2026-0042` |
| 律条 | 条文、出处 | |

搜索结果按当前官员的权限过滤。官员没有权限的那一类，会整类不出现。
