## 背景

- 新字段上线后，已有灵魂的出身地域全是「不详」。希腊流程会把「不详」直接交给米诺斯终审，所以希腊殿上线前要先补录一批。
- 现有的「批量导入灵魂」只能新建灵魂，遇到已存在的灵魂会报「重复」，不能用来更新。
- 网页编辑表单可以逐个改，但灵魂多的时候太慢。
- 后端会提供一个「按名单批量更新出身地域」的接口，流程和现有的批量导入一样：
  1. 上传 CSV；
  2. 预览每一行的结果；
  3. 确认后才写入。
- CSV 要有两列：灵魂标识(灵魂 ID 或灵魂编号，二选一)、出身地域(EUROPE / ASIA / 留空=不详)。
  - 多出来的列一律忽略，所以「导出灵魂」得到的文件只改出身地域那一列就能直接上传。
- 有错的行(找不到、取值不对、文件内重复)跳过，其余照写；预览里先标出哪些行会被跳过(产品 10-19 定)。
- 只能改本殿的灵魂；别殿的编号一律显示「找不到」，不透露对方存在。

## 要的稿(网页)

1. **入口放在哪**：灵魂列表页的工具栏(批量导入旁边)，还是批量导入弹层里的第二个页签？请定一个。
2. **上传与预览**：沿用批量导入的样子。预览表每行写编号、灵魂名、原值 → 新值、结果。
   - 结果分这几种：将更新 / 无变化 / 找不到 / 取值不对 / 文件内重复。
   - 表头上方写各类计数。
3. **确认与结果**：确认按钮上就写明「将更新 N 个，跳过 K 行」;完成后显示「已更新 N 个，无变化 M 个，跳过 K 行」,并列出被跳过的行和原因，给一个下载模板 CSV 的链接。
4. **空状态与出错**：文件格式不对、缺灵魂标识列(或两种标识列都有)、超出行数上限、没有任何一行能更新时，各怎么写。
