## 共同约束（v3 已定，代码里已落地）

**颜色**
- 中性色：canvas #EFEFEB / #10120F，surface #FBFBF8 / #1A1D19，ink #181A17 / #F0F1EA，muted #646861 / #A7ACA4，line #D1D3CD / #383C35。
- 文明色（浅 / 深）：
  - 地府 #8F3329 / #AD4B40
  - 欧洲 #583875 / #80609A
  - 埃及 #294A8A / #5F7FBE
  - 希腊 #285051 / #5A8480
- 文明色只出现在五处：匾（身份带）、导航当前项、印、主按钮、行首「待我处理」色标。组件整体是中性的。
- 状态色只有三种：
  - 冷玫红 #B42350 / #FF7A9A：只用于失败、出错。
  - 危险实底 #8F2430 / #C84C5A：只用于不可撤回的删除按钮。
  - 橙 #A65000 / #E07A23：只用于可撤回的危险操作。
- 判决与灵魂状态一律用「字形 + 文字」表示，不用颜色：
  - 判决：✓ 通过、✕ 不过、◇ 待定、↺ 重审
  - 灵魂状态：○ 在世、◇ 审判中、▣ 已处置、↻ 轮回中、≡ 已终结、◌ 迷失
- 图表不用彩色分类：
  - 灵魂状态用冷灰蓝明度梯度。
  - 去向按界分图案：炼狱实底、天界半色、地狱斜线、中立空框。

**形状与层次**
- 圆角：输入框和筛选标签 4px，弹窗 8px，其余一律方角。按钮保持方角（用户拍板）。
- 阴影只有两档：
  - raised：资料舱、批量条
  - overlay：弹窗、抽屉

**字号**
- 字阶共八档：11 / 12 / 13 / 15 / 20 / 28 / 40 / 56。
- 标题层级：
  - 页面标题 20 / 600
  - 面板标题 20 / 600
  - 列表行标题 13 / 500
  - 区块标签：11 号，大写，界面字体（不用等宽）
  - 正文 13
  - 首页封面标题 28
- 衬线体只用于「有人说的话」：律条、供词、判词。

**控件尺寸暂不改**
- 按钮 28 / 32 / 40，表格行约 40px。v3 的 44 / 48 / 56 和 64px 行高已记录在案，先不采用。
- 稿子请按现尺寸画；如果某页在现尺寸下明显太挤，在旁边标出来。

**表格行**
- 悬停：4% 墨色底。
- 选中：7% 墨色底，**不画行首竖条**。行首 3px 竖条只表示「待我处理」。

**批量条**
- 墨色反白实底。
- 条上的警示用条本身的字色加 ◐，不用橙色（橙色字在墨色底上对比度不够）。

**其他**
- 动效：80 / 160 / 240 / 320ms。曲线：进场 (.2,.8,.2,1)、出场 (.4,0,1,1)、强调 (.2,.8,.3,1)。减少动态效果时全部归 0。
- 三种界面语言：简体中文、English、古埃及语转写。埃及语很长：页题最长 28 字符，菜单项最长 21 字符。
- 宽度四档：1440 / 1024 / 768 / 393。
- 导航壳按 v3 第七轮，已在代码里实现：浅色中性导航、手风琴二级菜单、顶部 52px 工具栏、1024 强制收起、768 以下改为底栏。

## A. 第二批三类专用页面

这几类是组件库拼不出来的：它们各自的信息结构特殊，直接套表格会很难用。

每页请出 1440 浅色、1440 深色、393 浅色三张。审批流编辑器 393 下是只读，画只读态即可。

### A4. 仪表盘（`/dashboard`）

**现在有的：**
- 待办条三格：调派待批、审判队列、死亡同步异常。每格是计数加链接。
- 五个状态卡：在世、审判中、已处置、轮回中、已终结。
- 按文明的灵魂数与占比。
- 状态分布图例账、余额分布直方图。
- 最近动态：按动作分组，显示描述、人、时间。
- 按界域的灵魂数：柱状图，用图案区分界的类型。
- 管理员另有「账本」标签：平均余额、状态细分、界域前十表。

**请画：** 整页编排；这些图表按 v3 规则（冷灰蓝梯度、四种图案）的样子；待办条在没有数据、加载失败时的状态。

### A5. 朋友圈（`/social`）

**现在有的：**
- 动态 / 全部两个标签；发帖框（正文、可见性四档）。
- 帖子：作者、正文、可见性徽章、时间、评论数、表态数。作者可删除。
- 表态五种：赞 ◇、爱 ♡、敬 △、同情 ○、长明灯 ◉。长明灯最重，放在最后，样式与其他四种不同。目前没有分类计数。
- 详情：帖子加嵌套评论。评论可回复、可表态、作者可删除；回复时有「回复给」标签。
- 关注页：关注中 / 粉丝两个标签。
- 个人页：头像、简介、发帖数 / 粉丝数 / 关注数，编辑资料或关注按钮，下面是他的帖子。
- **图片：后端与 App 已经支持帖子配图（私有存储，签名地址），Web 目前完全不显示。** 请把 Web 上的图片展示与查看器一并画出来。

**请画：** 信息流、详情、个人页；长明灯在 v3 下的样式；图片宫格与查看器。

### A6. 权限矩阵（`/permissions`，管理员）

**现在有的：**
- 三段：矩阵 / 角色 / 定义。
- 矩阵：行是按类别分组的权限，列是角色；每个类别头有各角色的小计。393 下改为先选一个角色、再给一列开关。
- 单元格七种状态：
  - 已授 ■、未授 □
  - 待授 ＋、待撤 −（未保存，带强调环）
  - 失败 !
  - 冲突 ◇（撤掉后会让某个审批节点没人能批）
  - 始终（管理员列，不可点）
  - 禁授（不可点）
- 筛选框和「只看差异」。
- 未保存条：待改数量、确认冲突、放弃、保存。
- 保存确认弹窗：按角色列出差异、影响人数、需输入角色名确认。
- 图例与两类警示横幅。
- 角色段是表格加编辑抽屉；定义段是数据表格。

**请画：** 大矩阵在 1440 下的密度与吸顶表头 / 首列；七种状态的格子；未保存条（墨色反白，与批量条同一规则）；393 下的单角色开关列表。
