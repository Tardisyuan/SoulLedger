# 第二十四批 · 登录交付单的美化(请画稿)(2026-10-11)

第二十批的交付单已经做出来了,功能都对(样张见 `v3-pages/soul-login/delivery-slip-as-built.png`,就是按你的 `DeliverySlip.dc.html` 排的)。用户看了实际导出的 A4 后的意见:**太素了。这个系统本来分四种文明,交付单应该跟着各自的风格走,做得更高级一些。** 请重新出稿。

---

## 一、这张纸是什么

- 灵魂在这个系统里拿到的**第一件实物**:殿里的官员当面交给它,上面有它的灵魂编号和二维码,它据此第一次登录。
- 上联给灵魂带走,下联(存根)本殿留存,有签收线。
- 所以它既是一张凭据,也是这座殿给这个灵魂的第一印象。现在的样子像一张快递底单。

## 二、不能动的(功能和安全)

1. **A4 竖版,一页。** 上联仍是可以剪下来的一联(现在是 99 mm 高,和 DL 信封同尺寸;你要改高度可以,但仍要能剪、能折进信封)。剪切线保留。
2. **二维码**:内容 `SL1:<编号>`,不小于 42 mm,四周留白不少于 4 个模块,纯黑白、不能叠任何纹样或颜色,否则扫不出来。
3. **不印密码。** 留手写密码的空格(官员当面写,或不写)。
4. **编号**用等宽字、3-4-3 分组,是这张纸上最大的字,必须一眼找到。
5. 现有的每一项文字信息都要在(上联:殿名、灵魂名、编号、密码空格、有效期、「首次登录必须改密码」、二维码用法、交付官员、打印时间、「只发给本人,不要拍照转发」;存根:灵魂、编号、有效期、打印人与时间、两条签收线、「签收后请在官员台点『标记已交付』」;页脚:编号、页码)。文案不改;要改请单独列出来。
6. 存根可以比上联朴素——它是给档案柜的。

## 三、请你定的 6 件事

1. **黑白还是彩色?** 第十五批的打印规范是「黑白,强调用 ■ 和粗体,不用颜色」。殿里的打印机多半是黑白激光。我们的想法:**以黑白为准设计**(在黑白打印机上必须好看、清楚),彩色打印机上可以多一个文明气质色作点缀,但去掉颜色后不能丢信息、不能变脏。你如果认为应该只做黑白,或者值得为彩色单独做一版,请说。
2. **四种文明各自长什么样?** 系统里的四个文明和它们现有的气质(App 与官员台已经在用):
   - 中国 · 酆都(`CN_DIYU`):朱印、方角、殿名牌匾;
   - 埃及 · 杜阿特(`EG_DUAT`);
   - 欧洲 · 天堂 / 地狱(`EU_HEAVEN_HELL`);
   - 希腊 · 哈迪斯(`GR_HADES`)。
   请为每种文明给出交付单上**可以黑白印刷**的视觉语言:边框 / 角饰 / 分隔线的样式、殿印的位置与大小、标题的排法、有没有底纹(有的话要很淡,且避开二维码和编号)。四张的版式骨架请保持一致(同样的信息在同样的位置),差别在装饰和气质上——官员不该每换一个殿就重新找一遍编号在哪。
3. **殿印**:我们手里每个殿有 `seal_glyphs`(印文,一到几个字)和殿名。现在只在右上角印了一个小品牌标。请定殿印怎么用(大小、位置、是否压在某条线上)。没有印文的殿退回品牌标。
4. **「更高级」落在哪里?** 请说明你打算靠什么让它显得郑重:纸面的留白与比例、标题的字体与字距、细线与粗线的层次、编号的排法……而不是靠堆装饰。它应该像一张证件 / 文书,不像传单。
5. **字体**:打印走浏览器,能用的是页面已经加载的字体(现有的无衬线、等宽,以及 App 里文明气质用的那几套——请指明你要用哪一套、用在哪)。不能假设殿里的电脑装了别的字体。
6. **语言**:交付单跟着官员台当前的界面语言印(中文 / English / 埃及文)。装饰里如果要出现文字(比如殿名的另一种写法、格言),请说明三种语言下各印什么,或者只用不依赖语言的图形。

## 四、请画

- 四种文明各一张 A4(794 × 1123,黑白)。
- 其中一种(你选最有代表性的)再给一张彩色打印机上的样子,如果你决定做彩色点缀的话。
- 一张说明骨架的图:哪些区域四种文明共用、哪些区域是文明各自的装饰,以及二维码与编号周围的禁区。
- 装饰请用我们能照着实现的东西:线条、几何图形、现有图标集里的图形、文字;不要位图纹理。如果必须用新的图形(角饰、纹样),请给 SVG path。
