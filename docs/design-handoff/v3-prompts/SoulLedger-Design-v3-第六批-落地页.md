# SoulLedger · 规范 v3 · 给 Design 的第六批：落地页 `/` 重做(2026-10-03)

第五批(A9)重做了登录页 `/login` 和欢迎页 `/welcome`,两页已上线。根路径 `/` 的落地页不在那一批里，仍是 v3 之前的样子。用户看过，要求按 v3 重新设计。

请用本项目已同步的 v3 组件和令牌(按钮、面板、品牌标 `BrandMark`、品牌色 `--brand-mark` / `--brand-ground`、状态字形)。出 1440 浅色、1440 深色、393 三档。

## 一、这一页是什么

- 公开页面，不登录也能看。不经过官员台的外壳：没有侧栏、身份带、面包屑。
- 已登录的人也能打开。
- 页内入口：
  - 右上角「控制台」:未登录去 `/login`,已登录去 `/dashboard`。
  - 语言切换(简体中文 / English / Kemet)。
  - 明暗切换。

## 二、现在的样子(自上而下)

1. **顶栏**(高 64):左边是一个旧的线框图标加「SoulLedger」粗体字，不是天平标;右边是语言下拉、明暗切换、黑底「控制台 ↗」按钮。
2. **标题区**(左对齐):
   - 大标题「灵魂账本」
   - 副题「跨文明灵魂管理系统」
   - 一句说明：统一管理中国地府、欧洲天堂地狱、埃及冥界、希腊冥界四大文明体系的灵魂操作系统。
3. **「文明体系」**:2×2 四张白卡。每张卡有：
   - 文明名，例如「中国地府」
   - 小字地区，例如「中国」
   - 一行特征，例如「十殿阎王、孟婆汤、六道轮回」

   已登录时，自己所属的文明那张卡会标出「你的冥界」。
4. **页脚**(居中):「万古轮回皆有录」和「灵魂账本 v0.1」。

问题：

- 顶栏用的是旧图标，没有天平标，和登录页、官员台侧栏对不上。
- 内容只有一列，偏在左边，右侧大片空白;四张卡都是同样的白框，没有层次。
- 和 A9 登录页放在一起看，不像同一个产品。

## 三、必须保留

- 「控制台」入口，以及它按登录状态去不同的地方。
- 语言切换、明暗切换。
- 四个文明各自的名称、地区和一行特征，文案沿用现有的。
- 已登录时标出「你的冥界」。
- 产品名、副题、说明。
- 页脚那句话和版本号。

## 四、请给出

- 整体版式，以及天平标的位置和大小。请和 A9 登录页对照：浅色底上用墨色，深色底上用什么色。
- 四个文明的呈现方式：可以不是卡片;文明色只能用在 v3 规定的五处。
