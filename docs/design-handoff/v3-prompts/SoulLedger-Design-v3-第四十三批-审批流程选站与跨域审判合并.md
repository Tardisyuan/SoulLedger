# 第四十三批 · 审批流程「选站」与跨域审判合并(2026-10-18)

产品 10-18 定了一个新功能：审判类的审批流程不再固定走完默认流程的每一站，而是由判官选这次走哪几站；跨域审判并进审批流程，外域按顺序接在后面，由各域判官选自己那一段。下面写清现状、产品已定的规则和要的稿。zh-Hans / en / egy 三语照旧;egy 只用词表里已有的词。

用词：跨域审判(不写「会审」「联审」);站 = 审批流程的一个节点;域 = 一个文明 / 殿。

---

## 现状

- **审批流程**:审判结案时可勾「生成审批流」,或在网页「审批」页手动发起。流程按「文明 + 案件类型」取默认流程，例如中国的「十殿审判流程」,共十站：秦广王分流 → … → 转轮王终审。现在每一站都要走。
- **跨域审判**:在审判页「开跨域审判」,填标题、说明，然后请各文明入席(角色：联合审判官 / 主持 / 顾问，排第几站)。召集人可以结束或取消。结果只给受刑计划加外殿的受刑站，跟审批流程没有关系。
- 审批流程只属于一个殿，节点只能本殿的人审。

## 产品已定的规则(不用你定)

1. **生成流程时选站**:列出本域默认流程的各站，默认全选。判官取消勾选的站，这次直接跳过。**只有终审必须走**,不能取消。
2. **跨域审判并进来**:
   - 审判时，判官在「开跨域审判」里勾选参加的域，并排好顺序。
   - 生成流程时，各域的默认流程按这个顺序依次接在本域各站后面。
   - 各域依次走，不并行。
3. **各域同时选站**:流程发起后，各域判官同时收到「选站」待办，勾选本域这段要走哪几站。
   - 本域的站照常先走。
   - 走到某个外域那一段时，如果那个域还没选完，流程停下来等，并提醒那个域。
4. **中途加减站**:当前站的判官或本殿管理员可以把后面已跳过的站加回来，也可以把后面还没走到的站跳过。已走过的站不动，终审不能跳。每次都要写理由，留审计记录。
5. **流程走完就是跨域审判结束**。受刑计划给外殿加站的做法照旧;召集人「结束 / 取消」的入口保留。

## 要的稿

1. **生成流程时的「选站」**(网页结案弹层里勾「生成审批流」之后，以及「审批」页手动发起)
   - 本域默认流程各站的勾选列表：每行写站名、殿、审批人。终审那行锁定，写明为什么。
   - 如果这件审判挂着跨域审判，下面按顺序列出各外域，每个域只显示「由该域判官选站」和默认流程的站数，不在这里替外域选。
   - 全部取消时(只剩终审)怎么提示。
2. **外域判官的「选站」待办**
   - 网页：放在哪里(待办条 / 审批页的一个分组)。
   - 官员 App:待办里的一组，打开后是这一段的勾选列表加「确认」。
   - 选完之前，流程停在这一段门口时，本域和外域分别看到什么状态。
3. **流程详情页**
   - 各站要分「本域」与各外域几段来显示。每站的状态：已通过 / 已驳回 / 当前 / 待走 / 已跳过(选站时跳过 / 中途跳过) / 等待外域选站。
   - 「加减站」入口：谁能看到；选哪几站加回、哪几站跳过；理由。已走过的站与终审不可动，怎么标。
   - 官员 App 的流程详情(待办里打开)是否也给「加减站」,还是只给「在电脑上继续」。
4. **跨域审判页(网页)**
   - 原来的「入席 / 排第几站」:现在排的是各域的顺序。
   - 页上要能看到对应审批流程走到哪个域、哪一站。
   - 结束 / 取消入口仍在，取消会停掉审批流程里还没走的外域段吗?(请给文案，处理逻辑我们按「取消 = 外域段全部标为跳过」做，有异议请说)。
5. **空状态与异常**
   - 某个外域长期不选站(例如 3 天);
   - 外域判官没有权限或不存在;
   - 选站后又有人加减站。
