## 其余文字按这些规矩自己定

- **官员端:** 公文短句,动词开头,不用「你」。例:认领当前这一件。
- **灵魂端:** 对着人说话,用「你」,不用术语。例:你现在在哪。
- **空状态:** 可以带一句文明的说法,但不能编考据;拿不准就写平实的话。
- **出错:** 只说发生了什么、能做什么。不用文明说法。
- **已有的键先复用。** 仓库语言包里已有的词条(例如 `souls.diyu_station.*`、`judgment.offences.*`、`realms.names`)直接引用,不要另起一个意思相同的键。
- **标点全角,占位符写 `{{name}}`**,三种语言一致。
- **英文要好看:** 默认语言跟浏览器,访客多半看到英文。长度以第一批「长文本」那几条为上限。
- **排不下时**只能缩短这一批的界面文字,不能动判决文书和理由。
