第十六批 · 地图与插画的主角节点、魂火、两个 egy 词已回 · 2026-11-08

回复写到 v4-batch16-reply.md;新图放同一目录;文案三语写到 v4-batch16-zh.json / -en.json / -egy.json(扁平 键: 值)。第七至十五批已定的不动。

背景:用户觉得地图和插画「美观度差一点,没有科技感」

我们查过,原因有三:全是平涂、没有光和层次;几乎不动(只有当前站一个脉冲圈);图上没有数据。393 宽下整张图缩到约 310px,站名只剩约 4px。

用户定了:代码这边现在就做两件事(不用你出图),同时请你画「主角」部分。代码这边在做的:

  • 走过的线两层光(亮芯 + 柔晕),线上有沿路流动的「魂光」,世界图上流速按各站在押数;
  • 底下加 24px 细网格和刻度;当前站换成扫描环;线宽统一成几档;
  • 每站旁边加等宽数字小徽标(在押 / 容量),越满的站光越强,点站点出小卡;
  • 393 宽默认放大到当前站附近;空状态用本文明的徽记线描;落地页徽记卡后面加光晕和慢扫描线。

这些都叠在你第八批的 SVG 上,id、data-state、.edge、#labels 约定不变。

1. 主角节点的新画(四文明 × 深浅)

不重画整张图。只画每张图上的几个「主角」站点,做成等距或斜视角的小建筑 / 地标,替换现在的小方块或圆点。建议每个文明 3–4 个:

  • 每个节点一份独立 SVG,有「常态 / 当前站 / 已走过 / 未到」四种状态的写法(或告诉我们用哪些 CSS 变量换色);
  • 线描为主、颜色走矿物色与各文明的 glow 色;深浅各一套;
  • 尺寸:在 1120×450 的图里约 40–64px 宽,393 宽放大后也要清楚;

2. 落地页的「魂火」

落地页四张文明卡后面,想加一层慢慢飘的魂火粒子。我们自己用 canvas 写,不需要你出动画,只需要你定样子:

  • 颜色(各文明卡后是否用各自的 glow 色,还是统一一种)、粒子大小与疏密、亮度、飘动方向和速度、有没有拖尾;
  • 一张静态参考图(深浅各一),减少动效和低端机时就显示它;
  • 它和第二批定的徽记轻动画同时在,请确认不会抢戏。
