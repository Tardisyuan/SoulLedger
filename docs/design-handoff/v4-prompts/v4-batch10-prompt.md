## 1. 演示站的灵魂入口(新屏)

演示站(纯前端、Vercel、每次登录回原样)现在只有官员视角:网页本来就只给官员和管理员用,灵魂只在 App 里。用户决定:演示站加一个**灵魂入口**,在网页里模拟 App 的几屏,只在演示版有,正式网页不加。

- 范围:本世(「你现在在哪」四个模板)、书信、朋友圈、转生(只地府和希腊)。版式照第七批的灵魂端,不另起一套。
- 请定:入口放在落地页的哪里、和四张文明卡片的关系;进去后是一个手机框里的 App,还是直接铺满浏览器(393 宽下怎么办);怎么回到官员视角;一句告诉访客「这是 App 里的样子」的话。
- 灵魂端的锁屏实时进度、胶囊标签栏照 App(胶囊在 App 里暂时不透明、放页底,演示里同样)。
- 出深浅两套,桌面与 393 宽各一。

## 2. 加载时的说法

第七批的空状态每个文明有自己的说法(「这一殿今日无案」一类),加载还是通用的「加载中」。请给每个文明一句加载时的话,三种语言;出错提示保持直白,不用改。

## 3. 受刑状态按去处说

受刑计划的节点状态四文明共用一套(`sentence_plan.node_states.*`):未开始、调拨中、受刑中、刑满暂留、已完成、永久刑期、手动结束、已减项、随计划撤销。「受刑中」放在欧洲炼狱、埃及、希腊至福岛这些去处都不对。请按文明(必要时按去处类型)给一套叫法,三种语言;不需要换的状态写「沿用」。

## 4. 「第 N 世」在不转生的文明

不少地方写「第 {{n}} 世」(灵魂详情、账页分组、判决元信息、App 本世)。欧洲、埃及不转生,这样写不对。请给这两个文明的写法(例如只写「此生」、不写序号),三种语言,并说明 n 大于 1 时(调拨来的灵魂在别处转过世)怎么写。希腊转生但不是六道,也请看一眼要不要换词。
