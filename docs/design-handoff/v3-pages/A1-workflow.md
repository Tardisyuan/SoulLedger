# A1 · 审批流编辑器 —— Design 稿规格（从 claude.ai/design 项目「SoulLedger v3」取回整理，2026-10-02）

源：`templates/soulledger-v3-pages/WorkflowEditor.dc.html`、`WorkflowInstance.dc.html`、`WorkflowMobile.dc.html`。下面是稿里的数值与结构，逐条照抄，不是转述的感觉。外框（GlobalNav、52px 工具条 + 面包屑、身份带）用代码里现成的，不在这里重复。

## 编辑器 `/workflow/[id]`（1440 × 900）

**身份带**：题「审批流编辑器」，殿名「酆都 · 规制司」，右栏 meta「生死簿复核 · 已发布 v3 · 草稿 4 处改动」。

**工具栏**：高 64，`surface-1` 底，下边 1px `line`，左右 padding 16，间距 8。从左到右：
- 模板名输入：宽 180，高 44，1px `line-strong`，圆角 4，字重 500。
- 「文明 ▾」选择：高 44，前缀小字 11px `ink-muted`「文明」。
- 「案件 ▾」选择：同上，前缀「案件」。
- 优先级分段 0 / 1 / 2：每格 44×44，等宽字；选中格 `ink` 实底、`surface-1` 字；整体 1px `line-strong`、圆角 4。
- 版本徽章：`Badge glyph="✓"`「已发布 v3」；其后 12px `ink-muted`「◇ 未发布 4 处」。
- 弹性空白。
- 「! 校验 · N」次按钮（44 高）：无问题时 N 用 `ink-muted` 等宽；有问题时 N 与「!」用 `danger`。
- 「存草稿」次按钮。
- 「发布 v4」主按钮（`--color-main` 实底）。
- **加节点 / 自动布局 / 删除所选不在工具栏**（用户 10-02 拍板），见画布浮动条。

**主体**三栏，高度填满：
1. **节点调色板**（左，宽 176，`surface-1`，右边 1px `line`，padding 16/12）：
   - 区块标签「节点 · 拖入画布」（11px、大写、0.1em、`ink-subtle`）。
   - 四个 48 高的拖拽块，1px `line-strong`：`□ 审批`、`⧉ 会签`、`✉︎ 通知`、`■ 结束`。
   - 区块标签「角色 · 由连线推导」，下面 16px 字形列 + 12px `ink-muted` 说明：`▷ 入口 · 无入线`、`□ 步骤`、`◇ 分支 · 有条件出口`、`■ 终点 · 无出线`。
   - 底部 11px `ink-subtle`「角色不可拖，只能由连线得出」。
2. **画布**（中）：`canvas` 底 + 点阵（`radial-gradient(line-strong / .45 1px)`，16px 网格）。
   - 节点卡 168 × 60，`surface-1`，1px `line-strong`，padding 8/10；第一行 11px `ink-muted`「角色字形 + 角色名」左、右侧等宽小字（殿号 · 超时 / 门槛）；第二行字重 500「类型字形 + 名称」。
   - **选中**：`outline: 2px solid ink; outline-offset: 2px`（不用文明色）。
   - **有问题**：边框换 `danger`，名称行右端 `!`（`danger`、600）。
   - 连线 1.25px `ink-muted` + 箭头；「不通过 / 驳回」线 `stroke-dasharray: 4 3`。选中的条件出口线 2px `ink` + 实心 `ink` 箭头。
   - 线标签：固定出口（通过 / 不通过）是 11px `ink-muted` 文字，底色 `canvas`；条件出口是等宽 11px 小签「是 · 余额 < 0」「否 · 默认」，1px `line-strong` + `surface-1`；选中时反白（`ink` 底、`surface-1` 字）。
   - **右上浮动条**：right/top 12，padding 4，间距 8，`surface-1` + 1px `line` + `0 2px 8px oklch(0 0 0 / .08)` 阴影。三个 44 高按钮：「＋ 加节点」「自动布局」（幽灵）、「删除所选」（警示色描边 + 警示色字）。
   - **左下缩放**：1px `line-strong`，`−` / `100%` / `＋` / `⤢`，每格 44×44，等宽 12px。
3. **检查器**（右，宽 **360**，`surface-1`，左边 1px `line`）：
   - 标签行高 48：`节点` / `出口` / `问题 N` / `版本`；选中项下边 2px `ink`；问题数有问题时用 `danger`。
   - **节点页**：标题 h2 20/600「⧉ 三殿会签」+ 12px `ink-muted`「□ 步骤」。字段网格 `72px 1fr`，行距 8/12，标签 12px `ink-muted`，控件高 44、圆角 4：名称（聚焦态：1px `ink` + `0 0 0 2px focus/.35`）、类型 ▾、殿号 ▾、会签人（标签式多选，标签 `surface-2` 12px「宋帝王 ✕」）、门槛（56 宽数字 + 「/ 3 人」）、驳回到 ▾、超时（72 宽「48 h」+ 动作 ▾）。区块标签「审批人预览」，下面每行 44 高：姓名左、12px `ink-muted` 殿号右。底注 12px「3 人中任 2 人通过即放行」。
   - **出口页**（分支节点）：标题「◇ 复核 的出口」+ 说明「按顺序匹配，首个命中即走；都不中走默认」。每条出口一张卡（选中卡 1px `ink`，其余 `line`），卡头「序号 + 是 → ⧉ 三殿会签 + ↑ ↓」；条件行：字段 ▾ + 运算符（44 方格）+ 值 + ✕；条件之间 11px「且」；「＋ 条件 · 余额 / 文明 ∈ / 判决 ∈」；卡底「连线标签」+ 等宽预览「是 · 余额 < 0 · 文明 ∈ 2」。默认出口卡右侧等宽「默认」。虚线框 48 高「＋ 加一条条件出口」。底注「另有『通过 / 不通过』两个固定出口；本节点只用条件出口」。
   - **问题页**：标题「N 处问题挡住发布」+「点一条，画布定位到出问题的节点」。每条：`!`（`danger` 600）+ 500 字重的问题文案（用 `workflow.editor.issue.*` 的真实文案）+ 12px `ink-muted` 解释 + 11px 等宽 `ink-subtle` 问题码；当前条 7% `ink` 底。底注「共 16 种检查 · 14 种通过」。
   - 版本页：稿里只有标签，没画内容 —— 用现有版本历史。

**底部线性预览条**：高 44，`surface-1`，上边 1px `line`，12px，不换行。区块标签「线性预览」，然后「▷ 受理 → □ 初审 → ◇ 复核 → 是 ⧉ 三殿会签 / 否 ✉︎ 通知本人 → ■ 归档」（箭头 `ink-subtle`，条件签等宽 `ink-muted`），右端等宽「6 节点 · 8 连线」。

**三种状态**（稿用 `state` 切换）：选中节点（检查器开在节点页）、条件分支（分支节点 outline、条件线加粗、检查器开在出口页）、校验有问题（两个节点 `danger` 边、检查器开在问题页、工具栏校验数为红）。

## 实例详情（1440）

身份带：题「审批实例」，殿名「酆都 · 第三殿」，meta「生死簿复核 v3 · 第 4 / 6 步」。

三栏网格 `300px minmax(0,1fr) 320px`，间距 24，padding 24：
1. **节点列表**（`surface-1` 卡，1px `line`）：标签行 48「节点」（选中下划线）/「历史 · 7」。每行 64 高，网格 `20px 1fr auto`：已过节点 `ink-muted` + `✓` + 右侧等宽日期；**当前节点**：左 3px `--color-main` 竖条（「待我处理」，五处之一）+ 7% `ink` 底 + 字重 500，右侧「1 / 2」；未走节点 `ink-subtle` + `·` + 「未走」。底注 11px「行首竖条 = 待我处理 · 底色 = 当前节点」。
2. **当前节点卡**（padding 20/24，间距 16）：h2「⧉ 三殿会签」+「三殿 · 宋帝王主审」+ 右侧等宽 12px「剩 31 h · 超时升级」。会签人三格（1px `line`，每格「姓名 · 殿」12px `ink-muted` + 「✓ 通过 / ◇ 待签」；「你」那格 4% `ink` 底）。区块标签「你的判决」。**判决四键**每个高 74、等分：字形 24px 在上、文字 15px 在下；选中 2px `ink` 边 + 500。「备注」文本框（最小高 88，**衬线 15/24**，圆角 4）。按钮行：「提交判决」主按钮、「推进」次按钮、「升级到十殿」幽灵；右侧 12px「再有 1 人通过即进入 ■ 归档」。
   下面「最近一步」卡：网格 `96px 1fr`，等宽时间 + 「楚江王 · ✓ 通过」，下一行衬线 15/24 的备注原文。
3. **信息卡**（h2「信息」）：网格 `72px 1fr`：灵魂（姓名 + 等宽短 ID）、模板（名 + 等宽 v3）、案件、优先级（等宽）、余额（等宽，负数用「−」不用红色）、发起（等宽时间）、状态（「◇ 审判中」）。
