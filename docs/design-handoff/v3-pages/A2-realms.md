## 路线图（RouteMap，四种文明各一种空间语法；只读、不可点）

通用：区块标签（11px、大写、0.1em、`ink-subtle`）写形状说明；站点行网格 `12px 1fr auto`，间距 10：有灵魂 = 11×11 `ink` 实心方块；空 = 9×9 1px `ink-muted` 空框 + 名称与数字 `ink-muted`；右侧等宽 12px 在押数。底部图例（上边 1px `line`，11px `ink-muted`）：「■ 有灵魂」「□ 空」「数字 = 在押」+ 右端「只读示意」。

- **地府 · 一条直线**：竖线（1px `line-strong`，x=7）串起站点：鬼门关 → 黄泉路 → 望乡台 → 十殿 → 孟婆亭 → 奈何桥 → 六道轮回。
- **欧洲 · 漏斗，按层排**：三段，每段一个 11px `ink-muted` 小标题：「地狱 · 九圈，越下越窄」「炼狱 · 七层，越上越窄」「天堂 · 九重」。每层一个 1px `line-strong` 框（空层用 `line`），左右 margin 每层递增 8px 形成漏斗；框内：等宽 28 宽层号（罗马数字 / 阿拉伯数字 / 区间如「3–7」「1–9」）+「■ 名称」（空层「□ 名称」`ink-muted`）+ 右侧等宽在押数。层多时可合并成区间行。
- **埃及 · 主干后分过 / 不过**：竖线主干（杜阿特入口 → 十二时门 → 双真理厅 · 称心），下面一条横线分两栏：左栏实线竖边「✓ 过 · 心轻于羽」→ 芦苇之野；右栏**虚线**竖边「✕ 不过 · 心重于羽」→ **1px 虚线框**包着「阿米特」，框下 11px「≡ 吞噬即终结」。
- **希腊 · 主干后分左右**：主干（冥河渡口 → 三头犬之门 → 三判官之庭），下分两栏：左「← 左 · 向下」→ 塔耳塔罗斯；右「右 · 向上 →」→ 极乐之野（右栏右对齐，方块在右）。
