SoulLedger — current design tokens

Dark-theme values from app/globals.css. Light values and full notes in tokens.md.

This page is a point-in-time snapshot, not a reference. It was rendered to show the design review what the UI looked like going in, and every swatch below is frozen at that moment — status-alive, the surface ramp and the whole Civilization identity section have all moved since. The authority for current values is frontend/app/globals.css; the civilization tokens shown below (--color-civ-cn / -eu / -eg) no longer exist under any name and were replaced by the --color-civ-hue-* / --color-civ-mark-* pair for four civilizations, not three. Do not build against this page.
Colour is the only thing tokenised. There is no type scale, spacing scale, radius scale, elevation scale or motion token in the system — which is why the app has drifted to four heading sizes and four border-radius values. All five missing scales are part of the ask.
