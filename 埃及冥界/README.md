两条关于原 README 内容的说明：

**「五大核心神祇」表这一处原本是对的** —— 它写「阿努比斯 ＝ 心脏称重执行者 /
托特 ＝ 审判记录者」，与 Budge 1895《The Papyrus of Ani》图版 III 一致。
反倒是 `docs/02_奥西里斯审判详解.md` §3.1 把两者**对调**了（写成「托特调整天平」），
已于该文 v2.0 更正。详见 `docs/lore-verification/verify-egyptian.md` §2.2。

**「穿越十二门」这一步则沿用了错误定性** —— 十二门出自《门之书》，那是关于太阳神拉
夜间航行的王陵文献，不是亡者的行程；亡者行程的门在 BD 144/147（七道）与 BD 145/146
（二十一道）。正确说法见更正后的 `docs/03_杜阿特十二门详解.md` §一。
