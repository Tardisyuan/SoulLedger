This applies only to weighed Egyptian cases. "The forty-two denials" on the judgment desk: the deceased denies one wrong before each of the forty-two assessors, and you record each denial as True or False, with an optional note; the tally above counts true, false and not recorded. This needs the execute judgment permission, and the record cannot be changed once the case is concluded. Before the list is imported it says "The confession list hasn't been imported yet".
- The denials do not move the scale; the verdict still follows the weighing.
- If any denial is recorded as False, a Passed verdict is refused, naming the assessors concerned; this holds when concluding, when concluding a reopened case and when amending an appeal to Passed. It does not make the case Failed either: to go on, let the scale waver, which opens a new weighing. Cases with only true or unrecorded denials are not checked.
- A case that is not weighed hears no denials, and recording one is refused.
