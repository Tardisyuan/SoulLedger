Reference pages, mostly read-only:
- Deity roster: the mythological deities, including the forty-two assessors of Ma'at; needs the actors read permission.
- "Realm Management": table and topology; only capacity can be changed, with the realms manage permission (administrators by default).
- "Organization Structure": the organization tree; needs the org read permission, changes need the org manage permission.
- "Tenant Management": the list of halls. Officers who are not administrators see only their own hall's row; administrators see every hall. The fields are read-only except the seal glyphs on the plaque, which only an administrator can change.
- Menus and menu buttons: editing needs the menu manage permission, which by default only administrators hold.
- "Corpus": statute articles with a table of contents and search; "Copy citation".
